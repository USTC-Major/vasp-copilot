# PC-1 本地赝势库管理

基线：`436e5c9951a0a2446f2299a184db092d0abd9369`。本批实现用户已有本地库的只读登记和扫描；用户页面复测已通过，PR阶段补充Linux和容器验证。此说明不代表拼接或真实计算已经可用。

## 使用与边界

从执行设置或智能设置进入“本地POTCAR赝势库”（`/toolbox/potcar`）。选择后端所在电脑能访问的现有目录；父目录识别出多个集合时明确选择一个。填写显示名、可选版本备注，并确认有权使用该来源后登记，再主动扫描。

支持多库、默认库、改名、元数据／异常分页、扫描取消、同内容目录重关联、显式替换来源和仅删除登记。来源确认仅用于新登记和来源替换；扫描、改名、同一内容重关联不重复确认。版本备注由用户提供，数据集日期不等于发布版本。删除登记不删除源文件。

AI关闭仍可用。原始、gzip及Unix compress `.Z`均有读取和解码限额；源库只读，不复制整个库、不上传正文、不调用VASPKIT。只保存限定元数据与哈希。Windows中文、空格及特殊字符路径用文件系统API处理；不执行文件名、不跟随链接或reparse point。

首版识别PAW-PBE。其他家族、特殊小数氢变体、物种／体系冲突有明确状态，不静默修正或自动采用。格式检查通过不等于科学参数适用。**本批不提供POTCAR拼接、下载产物、工作流打包或AI自动使用。**

## 接口与恢复

管理路由统一为`/api/v1/toolbox/potcar`，由Toolbox执行服务拥有，独立后端及集成后端复用同一路由。登记／修改采用registry或library revision；后台每库单扫描、全局最多两扫描。取消和发布同步，完整扫描才替换索引；失败保留旧完整索引，重启不自动重扫。

重关联核验完整候选字节指纹；换源需要显式确认并废弃旧索引。候选分页绑定索引版本。应用库状态损坏返回该模块的结构化503错误，保留原状态文件，不阻断其他Toolbox能力。

默认限额：候选10,000、目录深度6、扫描120秒、单文件输入8MiB／输出16MiB及解码时间限制。修改限额需重新审查资源风险。解码器来源和许可见`backend/toolbox/potcar/THIRD_PARTY_UNLZW.md`。
