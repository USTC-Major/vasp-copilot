# 共享晶体查看器：旋转与缩放分离

日期：2026-10-11。基线 main `e1d9457ec741bb98dcbf00d2a2a0b6a86cfab3e2`。用户已通过 CAT-03／04 其余复测，本轮只修复共享查看器交互，不启动 CAT-05／06。

## 问题与已确认行为

原详细查看器每次旋转后根据二维投影包围框重新计算比例和居中位置。细长晶胞或带真空的表面在不同朝向下投影宽高变化明显，因此产生自动放大／缩小的观感；原实现也没有滚轮处理。

本轮将详细查看器的朝向、基准显示尺度与用户缩放分开：

- 拖动、方向键和标准／a／b／c 视角只改变朝向，保留缩放比例与固定旋转中心。自然投影缩短仍然存在，不人为保持二维轮廓不变。
- 首次载入确定初始适配；只有显式“适应”才根据当前朝向重新适配。“复位”恢复标准朝向和初始尺度。
- 画布内滚轮平滑缩放，以固定旋转中心为中心；归一化滚轮和触控板增量，保留倍率上下限、按钮和键盘缩放。画布外仍正常滚动页面。
- 小缩略图沿用固定标准朝向与自动适配。原子、晶胞、吸附位点使用一致的投影变换，不修改结构坐标、身份、约束或导出。

共享组件用于 Workflow、清洁表面、位点及吸附候选，无需分别新增显示实现。

实现上保存独立的“适应参考朝向”，并以固定晶胞中心为旋转中心。旋转不修改这个参考；“适应”以当前朝向替换参考并回到 100%，“复位”恢复标准参考与 100%。容器尺寸变化时按该参考调整显示尺度，不借 resize 改写用户朝向或结构数据。晶胞外原子和位点也须计入适应范围；选择标记只改变样式，不触发重新适配。

细节：实际保存参考朝向对应的对称投影范围，以 $(a+b+c)/2$ 为中心，使用各点投影的最大绝对距离保证偏离晶胞的原子／标记也可适配。详细图重新打开时保留已有视角和缩放；真正的晶格、原子坐标或身份变更会清除旧查看状态，重新打开时以新几何初始化。缩放沿用 60%—250% 边界；滚轮按像素／行／页单位归一化并限制单次增量，小幅触控板操作不通过整数百分比舍入丢失。
