# CAT-01／02：结构草稿与表面建模

CAT-03／04 的接续范围与实现约定见 [吸附构建说明](ADSORPTION.md)，验证状态见 [吸附构建回执](ADSORPTION_VERIFICATION.md)。本页保留 CAT-01／02 的已交付基础，下文关于吸附“后续阶段”的表述属于该基础切片的范围说明。

CAT-03／04 复测后的共享查看器修订见 [旋转与滚轮缩放说明](VIEWER_ZOOM.md)，不改变科学构建或导出行为。

本阶段实现 Toolbox 的独立表面建模入口。开发基线为 v0.5.0 / main `5366a19`；目标版本未定，合入源码不代表已发布安装包。

## 范围

- 导入本地 POSCAR／CIF，明确来源是体相还是已有表面；提供理想 Pt 结构用于体验。
- 晶面指数以用户提供的晶胞为依据，不静默转换成标准晶胞。
- 指定三指数晶面、最小厚度与真空、面内扩胞，生成并选择几何终止面。
- 识别原子层，按底层和逐原子例外调整约束，预览并独立导出 POSCAR 与来源元数据。
- 草稿包含来源、参数、当前选择和版本，支持恢复；过期版本不得覆盖新状态或导出旧结果。

本阶段尚不添加吸附物、自动吸附位点或接入 Workflow。这些分别属于 CAT-03／04 和 CAT-05／06；完整催化预处理首版仍包含这些后续阶段。

## 科学约定

输入厚度是生成器的最小目标，应同时展示生成结构的实际原子跨度和法向周期空隙。层分组容差是几何判据，不是普适的化学层定义。终止面编号表示几何候选，不表示能量或稳定性排序。

Selective Dynamics 的三个方向对应直接晶格基矢，不能按 Cartesian 标签解释为三个空间坐标方向。源文件不覆盖；导出原子顺序、约束、稳定身份与元数据行映射必须对应。变换无法可靠传递身份或混合方向约束时，应明确拒绝或保留为不支持，不作近似的静默映射。

CAT-00 已在发布锁版本核对理想 Pt(111) 的几何、库行为与导出链路。该证据不能外推为任意材料、极性／带电／重构表面或计算收敛的科学验证。本阶段不调用真实模型、MP、SSH、超算、VASP 或真实赝势。

## 验证边界

定向核对结构导入、指定晶面与终止面、约束和身份、重开恢复、过期版本、资源边界、导出重读，以及实际页面与后端闭环。复用 CAT-00 的库探针结论；不因新增页面而本地重跑全部旧功能。

## 接口分工

确定性接口位于 `/api/v1/toolbox/catalysis/drafts`，由 Toolbox 后端持久化，不依赖 AI 会话。创建／列出／读取草稿，带 revision 更新参数和当前选择；子路径 `/surfaces` 生成表面、`/constraints` 修改约束、`/geometry` 提供既有查看器的几何格式、`/export` 返回当前版本的导出包。

源结构快照与生成表面分别保存身份。生成结构的原子 ID 表示当前快照中的唯一原子，来源关联不伪装成跨扩胞的一一对应。输入角色为已有 slab 时直接进入分层及约束；体相先生成表面。新模块不借用后处理 dataset 的命名空间。

实际请求字段和错误码以 `backend/toolbox/catalysis/` 与 `frontend/src/types/catalysis.ts` 为准；实测记录及明确限制在本阶段实现收口时更新。

## 页面操作

1. 在 Toolbox 的“表面构建”入口导入结构，选择体相或已有 slab；也可先使用合成 Pt 示例。
2. 对体相设置 hkl、最小 slab 厚度／真空和面内倍数，生成后选择终止面。厚度采用 Å，不是层数。
3. 查看实际几何量和结构，按从底部计数的层数固定原子；在层列表中为个别原子指定固定或自由例外。
4. 应用并保存约束，再导出 POSCAR 与 metadata ZIP。勾选“先释放所有已有约束”会先清除已有固定方向，再应用当前层和例外。
5. 切换页面后从已保存草稿恢复。未应用的本机输入和后端保存的结构是不同状态；按页面提示保存或重新生成，再预览／导出。
6. 后续自行准备计算前仍须核对表面厚度、真空、磁性、偶极和 k 点等计算条件；本阶段导出文件不自动提交作业。

如另一页面已经更新同一草稿，本页需载入最新版本再操作。更改切面或扩胞后，旧原子 ID 的逐原子例外不能继续用于新结构。

## 当前支持边界

- 有序、有限、右手晶胞；不静默修复左手晶胞，不支持占位无序结构。体相至多 512 个原子，单个表面至多 2048 个原子。
- hkl 每个分量为 -3 到 3 的整数且不全为零；面内倍数为 1 到 8。生成前预算定向晶胞和输出原子数；最多 16 个终止面、合计 8192 个原子，不静默截断。
- 体相切面不做 primitive 化或晶胞标准化。带混合 T/F 方向约束的体相不能直接切面，因为变换后的基矢语义不能可靠保留；已有 slab 可保留混合方向标记并选择显式全释放。
- 原始结构文本限 2 MiB；草稿最多 128 份、每份 256 次修订，单修订 8 MiB，CAT 存储总量 256 MiB。达到限制给出错误，不覆盖已有数据。
- 已有 slab 根据 a×b 法向的最大周期无核空隙展开分析坐标来分层，原坐标不改。几何空隙不自动等于物理上充分的真空。

这些是本阶段工程支持边界，不是科学推荐参数或材料适用性的保证。
