# CAT-03／04：吸附物、几何位点与候选构型

后续单模型接入已由 CAT-05／06 完成，见 [Workflow 接入说明](WORKFLOW.md)。下文的阶段范围保留原切片说明。

基线：main `58ef673`（CAT-01／02 已合并且用户复测通过）。本轮实现单原子／单分子吸附构建；目标版本未定，不发布安装包。

## 已确认范围

沿用保存的清洁表面快照，选择一个吸附原子或导入 XYZ 分子，明确锚定原子、初始高度和旋转方式。CO 作为合成代表示例，几何尺寸不能宣称为优化后的科学推荐。

自动生成顶位、桥位、三重空位等几何候选，与手动位置共用放置逻辑。用户可多选位点，形成多个独立构型，每个构型只放置一个吸附物。一个 CO 分子包含两个原子，仍属于一个吸附物。

各构型有独立身份、源表面、位点、变换参数、原子及约束映射。支持预览、保存、恢复、筛选和多选导出，不按生成顺序或几何评分声称稳定性排序。

## 核心约定

- 显式把所选锚定原子平移到位点加法向高度的位置；不采用隐含的质心定位。旋转参考系和顺序须在页面及导出记录中一致。
- 表面原子的身份、坐标和已设置约束保留。新增吸附物原子默认自由；导出元素分组时，行映射、身份与 T/F 同步重排。
- 自动位点是几何候选；一般 hollow 不直接标为 fcc／hcp。只有材料与堆垛的判别依据充分且有测试支持时，才能细分。
- 显式检查重复坐标、近距离接触和周期镜像影响；几何阈值不等于普适的成键或稳定性标准。
- 源表面、约束或吸附配置变化后，旧位点／候选失效。旧 revision、旧原子 ID 和未应用输入不能继续导出；失败请求保留已保存快照。
- 兼容 CAT-01／02 旧草稿；新增候选仍在独立 catalysis 存储中，不依赖 AI 会话、模型配置或 Workflow。

## 验证目标

复用 CAT-00 的库行为探针和 CAT-01／02 的持久化基础。新增验证针对 Pt(111)＋CO、任意锚点与姿态、周期去重、来源和约束、碰撞拒绝、过期候选、导出重读和旧草稿恢复。真实浏览器只覆盖本次新增闭环，不重跑全部既有页面。

## 放置参考系

表面正交基采用 $e_1=a/|a|$、$e_3=n$、$e_2=e_3\times e_1$，其中 $n$ 为外侧上表面法向。XYZ 坐标先减去用户选定锚点，再依次绕固定的 X、Y、Z 参考轴作右手旋转，矩阵顺序为 $R_zR_yR_x$，然后映射到此表面参考系。

锚点目标为位点基准坐标加高度乘法向。手动 $u,v$ 沿表面晶格 $a,b$，范围为 $[0,1)$；其基准高度取上表面原子核平面。CO 示例的 C 位于原点、O 位于局部 +Z，键长 1.15 Å，仅是示例几何。任意 XYZ 不自动猜测主轴或质心定位。

批次中的硬几何碰撞应报告具体候选并拒绝整次生成，保留旧草稿。可调近接距离筛查只给出几何警示，不能据此声明化学合理或不合理。

## 候选批次与接口

每次成功生成替换当前候选批次，同一批次使用相同放置参数、每个位点生成一个独立候选。当前最多选择 16 个位点，候选原子总量最多 8192；原子数仍受单快照上限限制。此前修订文件保留，但页面只选择当前批次，避免把旧姿态与当前参数混用。

更换吸附来源／锚点、源表面或约束后，上一批记录标为失效并清除当前选择；候选自身的参数和结构不改写。失败请求不发布半批结果。

接口沿用 `/api/v1/toolbox/catalysis/drafts/{draft_id}`：`/adsorbate` 保存来源与锚点，`/adsorption/sites` 获取位点，`/adsorption/candidates` 生成批次，`/adsorption/selection` 保存候选选择，`/adsorption/export` 导出所选构型；既有 `/geometry` 增加候选读取。所有操作绑定草稿修订及有效父快照。正式字段以 schemas.py 与前端 catalysis 类型为准。

## 格式与几何支持边界

- 分子导入采用单帧普通 XYZ，坐标单位 Å，原子行仅包含元素及 x、y、z。最多 128 原子、正文最多 64 KiB；不静默忽略额外帧或扩展属性列。
- 自动位点来自顶层原子和周期平面的 Delaunay 网格：顶位为原子位置，桥位为网格边中点，三重空位为锐角三角形重心。这是几何枚举，不是表面对称性约化或完整化学吸附位点识别；方形面的四重空位等可用手动位置。
- 自动枚举限顶层 128 原子、a/b 长度比不超过 4；面内基矢须满足二维约化条件 $|a\cdot b|\leq\min(|a|^2,|b|^2)/2$（含浮点容差），使有限周期网格的近邻覆盖具有明确边界。程序不会擅自约化或修改用户晶胞。周期去重后最多 256 位点；超限明确拒绝，不抽样或截断。手动位置可用于自动枚举不支持的表面。
- 每个候选最多 2048 原子，每批最多 16 候选且总计不超过 8192 原子。位点多选生成的是多个独立模型，并非同时向一个模型添加多个分子。
- 首版仅构建上表面单吸附物；分子须位于顶面与下一个周期底面之间的空隙。若高度、姿态或真空不足，明确拒绝，不自动包裹到另一侧。
- 周期副本距离检查有独立计算预算，超出时拒绝并提示调整分子或晶胞。低于 0.0001 Å 的近乎重合会阻止生成；用户设置的较大距离阈值仅给出几何警示。
- 斜晶胞跨周期展开使用完整 c 向量，仅用于几何分析和展示；保存的源表面坐标、原子身份和约束不被改写。

## 使用顺序

1. 在“表面构建”保存并选定清洁表面，先应用固定层及逐原子例外。
2. 选择单原子、XYZ 分子或 CO 示例，指定锚定原子并保存吸附物。
3. 选择自动位点类型，或填写手动面内位置，生成位点；在俯视图和列表中核对并多选。
4. 设置锚点高度及固定参考轴旋转，生成独立候选批次。查看实际原子结构和最近距离信息，决定保留哪些候选。
5. 保存候选选择并导出。ZIP 中的 POSCAR 用于后续计算准备；配套来源、变换、原子行映射及哈希用于复核。导出不代表已经提交或完成计算。

草稿服务端状态与本机尚未应用的输入分开保存。切页或重开后仍需留意“未应用”状态；若另一窗口更新了草稿，应先载入最新修订再继续。更改源表面、约束或吸附物后需要重新生成，不能复用已失效的候选。

### 三维位点显示

“几何位点与独立候选”中的三维缩略图及放大视图只叠加当前勾选的位点。未选择时显示干净的表面结构；勾选与取消后即时更新。平面图和列表仍显示全部当前有效位点，用于选择和定位。

筛选不会重编号：例如只选择列表中的 S12，三维中仍为 S12。显示选择不修改原子、位点坐标或后端生成逻辑，也不是候选 ZIP 的导出选择。上游参数尚未应用或位点失效时，继续沿用既有预览保护，不显示旧位点。

## 本轮之外

多吸附物共吸附、覆盖度扫描、自动最低能构型预测、自动磁性／电荷选择不纳入本轮。单候选接 Workflow、表面 ISIF／k 点策略与完整首版验收属于 CAT-05／06，仍待下一阶段授权。PP-22A 澄清与 PP-M 的既定顺序不变。
