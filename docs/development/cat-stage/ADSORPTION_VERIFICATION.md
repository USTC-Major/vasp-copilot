# CAT-03／04 实现与验证回执

日期：2026-10-10。基线 main：`58ef67378618c8277cfe7a3545d4d58e912ac2ee`。范围为单吸附物、几何位点与多候选；不包含 Workflow 接入、作业提交或发布。

## 当前实现

在已有表面草稿上增加单原子、普通 XYZ 和 CO 示例来源，显式指定锚点、高度及固定参考轴旋转。顶位、桥位、三重空位与手动位置共用放置链路，多选生成独立候选，可保存、重新载入、预览和导出 ZIP。

候选保留父表面指纹、吸附来源、放置变换及原子身份；表面原子和约束不变，吸附原子默认自由。批次失败不会发布部分结果；源表面或约束变化后旧候选失效，旧修订不能继续读取几何或导出。旧 CAT-01／02 存档保持原有哈希定义。

具体格式、上限及科学适用边界见 [吸附构建说明](ADSORPTION.md)。自动位点只是几何候选，不提供吸附能、稳定性或任意晶面完整性结论。

- 后端首轮定向 10 项通过：8 项新吸附测试与 2 项直接受影响的已有表面测试；包含锚点、约束、斜 c 跨周期展开、碰撞与批次事务、失效、混元素 ZIP 和旧存档哈希。
- 后端审查补证 2 项通过：收紧自动网格适用条件，以及 Pt(111) 全部顶位、桥位、三重空位的双向集合核对。预期集合由解析最近邻和独立周期映像构造，不使用被测 Delaunay 过程生成。两项属于首轮测试的加强重跑，不把总数相加为 12 项独立覆盖。
- 前端 22 项定向用例通过：14 项吸附编辑器／API、2 项查看器、6 项直接受影响的父页面状态与冲突恢复。覆盖未应用输入、迟到响应、导出取消、409 载入最新修订并保留编辑，以及斜 c 平面标记对齐。
- 最终生产构建、10 个修改 TypeScript 文件的 oxlint、差异空白检查通过。构建保留既有大 chunk 提示；没有为此修改依赖或拆包。
- 批次失败消息补充具体位点后，仅对应碰撞用例补验 1 项通过；仍为 10 项不同后端目标，不累加重跑数量。
- 后端、前端与科学边界独立审查完成，无剩余阻断问题；真实 Edge／Chromium 加隔离本地后端的新增闭环通过，外部请求被阻断。

真实页面流程：保存带非平凡约束的 96 原子 Pt(111) → CO 示例改以 O 为锚点、绕 Y 旋转 90° → 自动顶位 16、桥位 48、三重空位 32 加手动位点 1 → 生成 3 个各 98 原子的独立候选 → 保存其中 2 个选择 → 整页刷新恢复 → 下载实际 ZIP。父表面逐原子数据保持，新增原子全部自由；位点、姿态及手动 u/v／容差恢复。未应用的姿态修改暂停旧候选预览和下载。

实际 ZIP 中两个 POSCAR 的文件 SHA、晶格、元素分组、全部坐标、行身份与 T/F 均核对通过，分数坐标最大误差为 $5.56\times10^{-17}$ 以内。配套 metadata 与保存快照一致。此结果证明软件导出一致性，不证明吸附构型稳定。

深色宽屏、浅色 640px 的位点及候选截图、真实结构查看器已审阅；窄屏页面 scrollWidth 为 632px，无横向溢出。首轮浏览器脚本在 reload 的执行上下文等待处发生竞态，随后直接从已经保存的草稿续跑刷新恢复与导出，没有重跑已通过的生成段，也没有删除失败记录。

最后错误提示补齐后，隔离后端实际优雅重启；只读核对已验收草稿仍为 revision 8、3 个原候选 ID、2 个已选候选，不重复生成或导出。
