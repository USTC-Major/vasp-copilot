# CAT-05／06：表面模型接入 Workflow

本轮在 CAT-01／02 表面构建、CAT-03／04 吸附构建及共享晶体查看器的基础上，将已确认的模型交给现有 Workflow。开发基线为 main `730d8f394bebc8a52b86554da9c4c290fcf3b330`；源码集成与正式发布分开记录。

## 接入边界

- 一次接入一个已确认的清洁表面，或一个有效的吸附候选。批量候选仍可使用原有导出功能；不自动建立清洁表面、气相吸附物和所有吸附候选的整套任务。
- 未应用的页面输入和已保存模型不是同一个状态。应先应用参数及约束，再接入；过期候选应重新生成，不能带着旧版本继续。
- 接入创建独立的结构快照。保留原晶胞、快照原子身份与顺序、Selective Dynamics、CAT 草稿及修订、清洁表面来源、吸附位点和放置变换。POSCAR 按元素分组时记录显式原子行映射，并同步对应约束。
- 后续编辑 CAT 草稿不静默更新已经接入的 Workflow。若需使用新模型，应再次显式接入；已有 Workflow 草稿需要明确替换或取消，并重新确认受影响的参数和 POTCAR 选择。
- 同一个 Workflow ID 改用不同的 CAT 快照时，也必须重新生成计划；不包含 POTCAR 的模式同样不能沿用旧结构的计划确认。
- 复用原有 Workflow、Recipe、输入文件生成与 POTCAR 库及组装。接入模型不代表自动批准赝势变体、磁性、泛函、DFT+U、偶极或其他科学设置。
- CAT 草稿延续已有持久化；本阶段不扩展成完整计算项目或自动执行系统，也不承诺整个 Workflow 编辑状态跨浏览器重启恢复。

## 科学设置与验证

接入后的默认流程为表面弛豫加静态计算。表面弛豫采用固定晶胞的 `ISIF=2`，只优化原子位置，仍受已保存的 Selective Dynamics 限制。固定原子与固定晶胞是两件不同的事。参见 [VASP ISIF](https://vasp.at/wiki/index.php/ISIF)。

普通弛豫 Recipe 的晶胞设置由明确的表面策略覆盖，并保留覆盖来源。用户手工提交与固定晶胞策略冲突的 ISIF 补丁时，必须显示冲突，不能假装已经应用或静默丢弃。

二维采样以 $a\times b$ 为表面法向；若 $c$ 与法向平行，使用 Gamma 中心的 $N_x\times N_y\times1$ 网格。倾斜 $c$ 不通过隐式晶胞变换修正，而使用纯面内的显式倒空间网格，保留晶胞、原子顺序和约束。面内密度延续现有 Recipe；二维采样不代表已经通过 k 点收敛测试。

显式网格首版不自动生成四面体连接表，因此倾斜晶胞与最终 `ISMEAR=-4/-5/-14/-15` 的组合明确拒绝；既有 DOS 配方的 `ISMEAR=-5` 属于这一边界。用户应检查展宽策略或另行准备输入，软件不静默替换方法。表面模型也不使用现有体相高对称能带路径。参见 [VASP KPOINTS](https://vasp.at/wiki/index.php/KPOINTS) 与 [VASP ISMEAR](https://vasp.at/wiki/index.php/ISMEAR)。

## 操作流程

1. 在“表面构建”中载入已有草稿或构建表面，应用所需固定层及逐原子例外。
2. 若需要吸附模型，先保存吸附物和位点设置，生成候选，再预览要使用的单个有效候选。
3. 从清洁表面或当前吸附候选传入 Workflow，核对结构身份和约束。已有工作流草稿时，选择确认替换或取消。
4. 在 Workflow 检查表面策略与计算参数，再生成计划。磁性、电子类型和其他方法选择仍需用户根据材料判断。
5. 沿原有入口确认 POTCAR 元素顺序及变体，或明确使用不包含 POTCAR 的导出模式。后者的输入包仍须补齐赝势，不能当作完整可运行输入。
6. 生成并下载工作流 ZIP，核对各步骤文件及来源元数据。后续步骤的 CONTCAR／CHGCAR 等仍按既有继承计划准备；本阶段不会运行 VASP 或自动提交作业。

验证沿用前阶段已完成的几何、吸附构建及查看器证据。本轮补充模型接入、来源和约束传递、旧确认失效、生成及实际导出包重读的闭环。软件生成与文件一致性不等于真实 VASP 收敛或吸附能验证。

定向验证、实际浏览器下载包核对及集成状态见 [验证回执](WORKFLOW_VERIFICATION.md)。
