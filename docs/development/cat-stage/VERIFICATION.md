# CAT-01／02 实现与验证回执

日期：2026-10-10。基线：main `5366a19d5a104b812e936e0e606d67685d5a8ef4`。范围为独立结构草稿与表面构建，不包含吸附构建、Workflow 接入或发布。

## 实现

- 新增 Toolbox catalysis 模块与独立页面，支持 POSCAR／CIF、已有结构记录和理想 Pt 示例；区分体相和已有 slab。
- 输入晶胞定义保持明确，指定 hkl 后生成并选择终止面；提供层分组、固定底层和原子例外，复用原有结构查看器。
- 草稿在 Toolbox 数据根的 catalysis 目录保存，修订不可变且带指纹，最后原子发布 head。发布失败仍可读取旧版本并重试。
- 显式版本检查覆盖修改、几何读取与导出；未应用的编辑暂停旧预览／下载。本机未提交输入单独恢复，不覆盖较新的服务端修订。
- 导出 POSCAR、metadata.json 与 manifest.json；元素分组后同步行映射及约束。生成原子身份唯一，保留来源及周期映像关联。
- 修复结构上下文遗漏 coordinate_mode，并同步从正文派生 selective_dynamics；本阶段未接入表面计算参数策略。

浏览器闭环：不填名称创建 Pt 示例 → 保存名称 → (111) 生成 → 选择第二终止面 → 固定底部两层、释放一个底层原子、固定一个顶层原子 → 导航离开并整页重开 → 修改上游参数暂停旧结果 → 载入保存状态 → 下载 ZIP。结果为 96 原子、32 个全固定原子；当前没有 primitive 化，原子数不应套用 CAT-00 primitive 样例的 24 原子。

深色 1440px 与浅色 640px 关键状态无横向溢出。未宣称覆盖所有移动端尺寸、浏览器和操作系统。首次浏览器脚本在下拉选择器查找时序处中止；修正脚本后才执行有效闭环，不将该脚本失败当作产品失败，也不删除历史日志。

详细查看器另作只读补验，展开结构、所选原子的 FFF 标记和沿 c 视角在两种视口可读。最终导出新增 input_snapshot 后仅补验该字段及相关哈希：4 个输入原子身份可解析到 96 个输出原子的来源关系。Python canonical 快照指纹与 ZIP manifest 的两项字节哈希均通过；不以 JavaScript 对浮点数的重新序列化代替 Python 规范化字节定义。

后端环境使用 Windows 发布锁匹配的 Python 3.12.7、pymatgen 2026.9.24 / pymatgen-core 2026.10.2、NumPy 2.5.3。该环境未安装 pytest，仅为测试入口从既有开发环境的 site-packages 尾部加载 pytest，禁用自动插件；没有安装或更换科学依赖。前端复用经依赖锁核对的 node_modules，未修改依赖或锁文件。
