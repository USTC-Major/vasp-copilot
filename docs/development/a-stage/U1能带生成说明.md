# U-1 常规能带生成说明

本批只恢复 Workflow Builder 的 PBE／已有 PBE+U 输入生成链；不表示已经完成真实 VASP 能带计算或科学结果验收。后续两种 DFT+U 形式、DAG、Recipe 展示及绘图仍按各自任务处理。

## 启用与操作

服务端仍默认关闭能带能力。需要使用时，在后端启动进程的环境中设置 `ENABLE_BAND_WORKFLOW=true`，并重启后端；旧 `ENABLE_BAND` 仅作兼容，前者优先。前端读取 `/api/v1/bootstrap` 的实际能力；直接在请求中传 `enable_band_workflow=true` 不能绕过关闭状态。配置读取失败时可重试，其他计算任务仍可使用。

1. 上传已确定用于静态计算的 POSCAR（或将完成弛豫后的 CONTCAR 作为新结构上传）。
2. 选择 `static` 和 `band`，移除默认选中的 `relax`；可同时保留 DOS。确认电子类型、已有 DFT+U 参数及资源设置。
3. 审阅确认摘要、计划及文件继承关系，再生成、预览和下载输入包。
4. 使用相同结构和合适的 PBE POTCAR 完成 static；核查其实际收敛情况后，将 CHGCAR 按计划继承到 band。文件生成成功不代表该依赖已经满足。

本功能不提供 POTCAR，不通过 VASPKIT 生成或拼接 POTCAR，也不能凭空核验用户随后配置的赝势。输入参数与赝势的科学适用性仍须用户复核。

## 当前明确边界

- 不支持同一生成请求内 `relax → static → band`：弛豫可能改变晶胞，旧高对称路径不能直接沿用。应先完成弛豫，再用实际最终结构重新生成并确认 `static → band`。
- 首批不支持 SOC、非共线、混合泛函或 meta-GGA 专项能带，也不新增连续调度、能带绘图及反折叠。
- 高对称路径采用 Setyawan–Curtarolo 约定，对称识别容差为 `0.01 Å`。只对能够验证与标准原胞具有同一物理朝向、晶格和原子对应关系的原胞转换倒易分数坐标。允许经验证的整数幺模等价基底；常规胞、超胞以及无法可靠映射的旋转胞明确拒绝，不静默改写 POSCAR。已经是原胞但朝向不匹配时，也需要用户提供经核验的标准原胞；不能把拒绝解读为材料本身有问题。
- quick／standard／high 的线模式分别为每段 40／60／80 个点（含端点），不是均匀网格 KPPA，也不保证该采样已经满足科学收敛要求。
- 现有 Dudarev PBE+U 能带限定 d／f 轨道，static 和 band 的 DFT+U 设置必须一致；生成 CHGCAR 的上游与读取它的下游分别检查所需 `LMAXMIX` 下限（d 为 4，f 为 6）。确认后的参数编辑仍须满足这些条件。

## 验收范围

按[工作流验收合同](工作流验收合同.md)执行能力开关、普通与自然语言入口、重放生成、文件继承、实际 KPOINTS／INCAR 和 ZIP 检查。测试或本地页面使用合成结构时须明确标注，不将受控输入生成、Docker smoke 或替身 LLM 当作真实计算验证。
