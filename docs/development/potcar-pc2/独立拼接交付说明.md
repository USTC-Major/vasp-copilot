# POTCAR 独立拼接（PC-2）

入口：`/toolbox/potcar/assemble`，可从本地赝势库管理页进入。无需启用AI或旧工作流POTCAR开关。此阶段只做独立产物，尚未接入工作流ZIP。

## 使用流程

1. 在库管理页登记、扫描自己的现有PAW-PBE库；首次登记确认来源使用权限。
2. 进入拼接页，选择已有库，粘贴完整POSCAR或读取UTF-8文件（最大2MiB）。旧格式缺少元素行时按数量行填写显式映射。
3. 点击“读取 / 刷新预览”，按实际物种块顺序查看候选。不按化学式或字母排序，不合并重复物种块；唯一兼容候选可预选，多候选需要明确选择。
4. 改选后刷新预览，核对元素顺序和变体，勾选确认后生成。库许可不重复确认。
5. 下载POTCAR。页面只显示清单与哈希，不预览赝势正文。格式通过不代表科学最优或收敛性验证。

## 接口和恢复

前缀`/api/v1/toolbox/potcar`：`POST /previews`、`POST /artifacts`、`GET /artifacts/{id}`和`GET /artifacts/{id}/download`。沿用Toolbox错误包装。结构、来源身份、索引和逐物种选择绑定服务端预览；不信任客户端自行声明的文件哈希。

- 预览有效30分钟，后端重启后需重新预览；改变结构、库、映射或变体会撤销确认。
- 生成前重读选中文件，核对压缩源和解码字节指纹，用同一份校验后的bytes拼接，不改换行、字段或源文件。总产物最大32MiB。
- 源文件变化、库替换、旧索引或扫描进行中时阻止生成。按错误提示重新扫描、刷新和确认，不静默换库或变体。
- 同一确认的网络重试使用相同幂等标识，不重复发布；不同确认不能复用同一个标识。
- 完整产物与manifest原子发布，24小时内可重复下载，重启及来源变化不会改写已有快照。下载为attachment、no-store，下载前复核产物大小和哈希。
- 过期产物拒绝下载；当前尚未自动清理过期快照的磁盘占用。异常中断遗留的暂存目录不会作为成功产物公开。

## 边界与验证

不内置／下载／分发真实赝势，不调用VASPKIT或LLM生成POTCAR，不注册AI工具，不写入通用FileStore正文预览，不修改输入科学参数、自动上传或提交计算。

自动化使用明确的合成数据覆盖raw/gzip/Unix compress、中文路径、重复及零数量物种块、旧格式映射、源变更、确认／幂等、过期、重启、原子发布失败及字节完整性。Windows符号链接构造在无权限时明确跳过，Linux检查须由对应CI另行执行。软件合成流程通过不能等同于真实赝势、VASP运行或科学结果验收。
