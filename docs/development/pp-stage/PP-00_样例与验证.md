五份公开 XML 实际均为双自旋，不能按材料名“Al／Si／LiF”推断非自旋。本轮发现这一点并如实保留；真实非自旋 XML 仍需补齐。上游文件名包含 bands 也不自动证明已验证高对称分段。

原始公开文件只存于本机隔离证据目录；Git 中保留[固定来源和 SHA256](evidence/upstream-fixtures.json)及[许可证](evidence/upstream-MIT-LICENSE.txt)。用户原始输出不随此文档分发。科学数据读取一致仅证明解析结果匹配源数组，不证明原始计算收敛、模型适用或材料性质正确。

## 实际发现

1. **现有诊断 XML 解析不适合作为绘图数据入口。** 它只读取少量摘要；保持现有诊断行为，PP 另建有限适配层。
2. **成熟库也需要完整性检查。** 手写文件声明 2 个 k 点，实际只有 1 个时，两版 `Eigenval` 均未拒绝；输出数组为预分配形状，缺失内容可能留零。产品必须比较声明／实际计数并检查每行、维度和有限值。
3. **无独立 VASP DOSCAR 类。** 两个实测版本均无 `pymatgen.io.vasp.outputs.Doscar`；不能将 LOBSTER 的同名输入冒充 VASP 数据。XML 优先，DOSCAR 有限适配单列验收。
4. **结果回传有真实接口缺口。** 当前允许三种文件、32 MiB；新增 DOS／能带取回要扩展服务端协议与来源校验，不能只改页面文件列表。
5. **有限差分的运算可行，但完整产品成本仍未实测。** 简单数组差分通过，真实 CHGCAR 大文件、体渲染、内存上限、构型一致性仍属于 PP-07／12。

## 复现

1. 按 `evidence/upstream-fixtures.json` 的固定 URL 下载文件，并保留清单为 `manifest.json`；文件名使用清单的 `name`。先核对 SHA256。公开样例的 gzip 仅用于此研究探针。
2. 在已安装项目依赖的 Python 环境中，从仓库根执行：

```powershell
python -B -X utf8 scripts/research/pp00_parser_probe.py --fixtures <样例目录> --output <结果.json>
```

3. 可选 `--local-sample <本地test1-ok目录>` 只读取明确指定的本地样例，输出统计与指纹，不复制原文件。没有该私有目录也能运行全部公开及合成探针。

探针只用于可信研究样例，gzip／XML 读取未实现生产资源防护，不能直接接到上传接口。运行不会访问模型、MP、SSH 或 VASP，不读取用户配置、凭据或 POTCAR。
