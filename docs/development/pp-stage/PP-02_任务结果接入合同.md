用户已授权本批实现、必要验证、PR 和满足合并条件后的集成；不发布正式版本，不运行真实模型或超算计算。PP-M 后置，PP-22A 等其他功能不随本次开工。

## 1. 本次闭环

已有任务 → 明确项目／任务／步骤／提交尝试 → 预览可用文件、组合建议和大小 → 用户确认取回 → 本地不可变快照 → 现有 DOS／band 解析、绘图、保存与导出。

本地导入入口继续可用。任务入口负责来源与文件取回，不新建科学解析器、绘图算法或 AI 配置。不扩展当前科学格式、自旋支持矩阵，也不默认下载整个目录、POTCAR 或 WAVECAR。

## 2. 来源与文件边界

- 复用既有执行服务的项目、任务、作业、提交尝试、授权执行记录、远端目录和目标绑定校验。用户不能提交任意远端路径绕过任务身份。
- 仅接入具有可信提交记录、已提交且达到允许终态的尝试；失败或未收敛任务可取回数据，不代表解析会成功，更不代表科学收敛。
- 原诊断结果下载权限不扩大；PP 使用独立的受限文件集合和传输入口，复用既有 SSH 连接与受验证 helper。
- 科学文件候选限于现有 PP 支持的 `vasprun.xml`、`DOSCAR`、`EIGENVAL`、`INCAR`、`KPOINTS`、`POSCAR`、`CONTCAR`。根据分析类型提出组合，缺失文件、歧义和未知布局如实提示；不同时混入多个主结果路线或不明确的两份结构。
- 远端符号链接、非普通文件、超限文件、来源在预览／下载期间变化，以及尝试或目标发生变化时明确失败；不把部分下载当成完整科学快照。
- 单文件／单批／总缓存限制沿用 PP 资源边界；选择后核对总大小及本地空间。显示无法确认的信息，不伪造大小或可用空间。

## 3. 取回、缓存与恢复

- 下载为服务端有状态工作，界面显示进度、当前文件、失败原因和取消入口。切页不自动取消或丢失下载身份。
- 取消／断线／超时后清理临时数据，不将残缺文件提交为成功快照。失败可由用户重试；重试不覆盖已有完整分析。
- 缓存记录保留来源身份、所选文件、大小、指纹和取回时点。重开已完成快照无需远端可达；仅重开缓存不能声称已检查远端最新状态。
- 手动刷新重新预览、确认并取得新快照，不悄悄覆盖旧分析或改变其图形来源。刷新是否成功与缓存是否存在分别展示。
- 服务重启后的中断任务应恢复为可解释状态；不得永远显示正在下载。下载与解析生命周期正确关闭，不影响其他运行服务。
- 新源数据仍经现有独立解析 worker，使用原有解析状态、错误和配置持久化。文件 hash 与来源应在页面及数据导出中可核对。

## 4. 最小验收目标

| 范围 | 本批需要证明 |
|---|---|
| 身份边界 | 错项目／任务／尝试、无提交证据、目标变化、非终态不读取；任意路径或非允许文件不可导入 |
| 远端协议 | 元数据和分块读取有界；链接、来源变化、损坏／乱序帧、超限与取消被正确处理；旧诊断下载行为保留 |
| 来源一致性 | 同一公开样例通过本地和任务入口得到相同科学数组／能量参考，只有来源元数据不同 |
| 缓存 | 离线重开、显式刷新新快照、同名不同任务隔离、失败重试和重启中断状态正确 |
| 页面 | 选择来源、文件组合、大小／缺项、确认、进度／取消／失败、缓存查看；窄屏可操作，原绘图更新机制保留 |
| 导出 | 曲线与源快照一致，JSON／CSV 的来源身份和文件指纹可追溯 |

后端执行针对本批代码和关键失败路径的测试；前端执行受影响组件／流程测试，集成后必要构建和浏览器检查。已有效证据不由各代理重复运行。真实 SSH／HPC 未实际连接时明确标为未验证，不以假传输证明站点兼容或科学收敛。
