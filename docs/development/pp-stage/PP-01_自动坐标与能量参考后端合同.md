# PP-01 自动坐标与能量参考后端合同

本候选实现只改变显示视图和投影求和；解析得到的 `result.json` 科学数组保持源能量坐标。测试与新预览应使用独立状态目录，现有 7518、10327 和真实安装状态均不用于迁移验收。

## 视图版本与能量参考

`view.version = pp.view.v2`。保留 `reference`、`reference_ev`、`mirror_down`、`atoms`、`orbitals`、`band_start`、`band_end`，新增 `energy_min_ev`、`energy_max_ev`、`elements` 和 `projection_grouping`。

| reference | 显示能量 | reference_ev 的含义 |
| --- | --- | --- |
| raw | $E_{\mathrm{source}}$ | 不使用；高级原始能量模式 |
| fermi | $E_{\mathrm{source}}-E_F$ | 不使用 |
| custom | $E_{\mathrm{source}}-E_F-\Delta$ | 相对费米能级的偏移 $\Delta$，单位 eV |
| legacy_absolute | $E_{\mathrm{source}}-R$ | 旧版绝对参考 $R$，仅兼容既有缺费米值的视图 |

新自定义偏移默认 0；偏移 +1 eV 使显示能量减小 1 eV。DOS 在横轴向左平移，band 在纵轴向下平移。没有可信 `efermi_ev` 时，新 `fermi` 和 `custom` 请求返回 `400 / PP_MISSING_FERMI`，不假定费米能级为 0。API 不允许从普通 v2 视图新建 `legacy_absolute`，也不允许修改已保留的旧绝对参考值；该模式可继续改变能量窗或主动切换到原始能量。

`curves.reference_ev` 保持旧响应含义，即实际从源能量减去的总参考值；新增同义的 `effective_reference_ev`。`view.reference_ev` 在 v2 custom 中是偏移，二者不能混用。

## 自动坐标与完整数组

新分析有费米能级时默认 DOS 能量窗为 −5～3 eV，band 能量窗为 −3～2 eV；缺费米能级则使用明确标记的原始能量及完整可用能量范围。能量窗只接受有限、递增的起止值。

`view.axes` 仍使用 `pp.axes.v1` 形状，作为后端计算的显示坐标响应。v2 请求可省略 axes；提供时校验其形状，再根据能量窗和当前选中曲线重算，不接受手动覆盖纵轴密度或刻度的语义。

- DOS 横轴严格使用能量窗；纵轴只使用窗内当前总 DOS 与已选投影的可见值，包含窗边界与折线的交点插值。向下自旋镜像参与坐标计算，但返回和 CSV/JSON 的 DOS 数值保持原符号。
- 无窗内数据和全零 DOS 使用有效的后备纵轴：普通显示 0～1，具有 down 通道的镜像显示 −1～1。无窗内数据附提示。
- band 横轴严格使用完整 kpath 距离端点，不增加 padding；能量纵轴严格使用能量窗。断开的路径段仍分别生成曲线。
- 两轴刻度间隔自动选择；密度纵轴保留适量空隙，完整 kpath 和能量窗端点不向外取整。
- 完整能量范围响应为 `energy_bounds_ev: {min_ev, max_ev}`，基于当前能量参考与选中能带。前端也可根据已收到的完整曲线数组计算，避免读取旧草稿状态。
- `fit-axes` 路由继续提供当前请求参考/筛选的完整范围及自动坐标，返回 revision，不保存。v2 前端的“查看完整能量”使用完整曲线或这一响应更新能量窗。

任何视口都不截断曲线数组。JSON、CSV 与 PNG 使用同一已保存视图和自动坐标；CSV/JSON 保留完整曲线数值及来源指纹。既有响应规模上限继续生效，超限会拒绝返回，不悄悄截断。

## 投影选择与单位

`elements` 是元素范围，非空 `atoms` 是精确原子范围；二者非空时取交集。`elements` 为空时，可独立使用 `atoms`。`atoms` 为空且 elements 非空时包含这些元素的全部原子。

v2 的元素和原子数组都空时恒不显示投影，即使仍勾选轨道；轨道数组为空时也不显示投影，保留元素/原子选择以便再勾。新分析轨道默认全部可用源分量，元素/原子默认空，仅总 DOS。界面取消某元素全部原子时同步取消该元素；部分勾选的元素由前端序列化真实原子集合。

`orbitals` 支持实际可用的源分量和对应 `s/p/d/f` 角动量族。每个源投影最多计入一次，同时选 `p` 和 `px` 不会重复求和。这里不推断晶体场对称性，不自动命名 $t_{2g}/e_g$。

`projection_grouping = element` 为每个元素生成独立求和曲线；`combined` 保留旧版合计曲线。稳定 id 为 `dos.total.{channel}`、`dos.projection.{element}.{channel}` 和旧合计的 `dos.projection.{channel}`。元素曲线包含 `element`、`atom_ids`、`element_index`；后者是按源原子序号首次出现的元素顺序，筛选与显示排序不会改变它。合计曲线的 element/index 为 null。

顶层 `units` 明示 `energy=eV`、`dos_total=states/eV/cell`、`dos_projection=states/eV`、`kpath=Å⁻¹`、`reciprocal_convention=2pi`。总 DOS 对应源晶胞；投影曲线是所选原子与轨道的求和，没有除以原子数，不能标成“每原子平均”或 a.u.。每个投影曲线同时携带 `normalization=sum_over_selected_atoms` 与 density_unit。

## 旧视图迁移与并发

旧版不带 view version 的 ready 快照只迁移一次并增加 revision。DOS 的旧 axes.x 起止、band 的旧 axes.y 起止成为新能量窗。旧自动初始化窗与人为保存窗缺少来源标记，无法可靠区分，因此一律保留，不替换为新默认。旧非能量轴和刻度改为自动派生。

有费米值的旧 custom 绝对参考 $R$ 转为偏移 $\Delta=R-E_F$；实际显示仍减去 $R$，旧能量窗不跳。缺费米值的旧 custom 保留为 legacy_absolute，显示明确提示“旧版绝对参考”。旧筛选的空轨道“全部”转换为显式全部源分量；旧仅轨道且空原子“全部原子”转换为显式全部源元素，保留 combined 求和。迁移不重写 result.json。未知未来视图版本会拒绝读取并保留文件，不猜测其参考语义。

PATCH view 继续要求 expected_revision，校验与写入在同一锁内完成，成功响应返回增加后的 revision 和完整派生视图；同版本并发请求仅一次成功，其余返回 `409 / PP_CONFLICT`。前端应串行合并最新草稿，并在冲突后刷新最新记录、重放最终草稿；用操作序号丢弃迟到响应，避免快速操作回退。后端不会绕过 CAS 覆盖新状态。
