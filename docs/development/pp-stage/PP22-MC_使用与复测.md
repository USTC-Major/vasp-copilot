# 多计算卡使用与复测

本说明对应 PP22-MC 候选，实现与验收状态见 [计划与验收](PP22-MC_计划与验收.md)，不扩大 v0.5.0 正式安装包的功能范围。

## 使用顺序

1. 在基础能量分析中选择“吸附能”或“材料形成能”，创建一份分析。两种类型分别建分析。
2. 导入 OUTCAR、样本 CSV，或复用已有任务的完整本地快照。样本来源、原始值及人工覆盖依据仍可追溯；导入本身不代表科学收敛。
3. 建立计算卡，在当前卡选择参考和目标。可以让同一样本参与多张卡；每张卡独立配置计算口径与参考定义。
4. 吸附能卡选择一份清洁表面、一份吸附物参考、参考单元数 m，以及一个或多个目标和各自吸附物数量 n。形成能卡为涉及的每种元素选择参考，再选择材料目标。
5. 在当前卡核对设置，集中查看并接受明确列出的可接受风险，确认锁定后计算。另一张卡尚未配置完成不会阻止当前卡计算。
6. 如需修改，在当前卡操作区解除锁定。单纯解锁保留仍有效结果；修改科学配置后该卡重新确认。显示名称修改不改变计算有效性。
7. 修改或删除共享样本时先核对影响列表。引用它的卡需要重新确认，未引用它的卡不受影响；取消操作不修改数据。下载时区分“当前卡计算结果”与“可回导样本表”。

规则填入是可修改的建议，不能证明参考态适用；组成比例也不能代替真实分子／片段数量定义。软件只阻断能够确定的输入、计量和状态错误。

## 多卡交互

左侧选择计算卡，右侧编辑当前卡。草稿随卡保留；先确认页面保存状态，再关闭或切换设备。本地草稿恢复不能代替服务器保存，冲突时不能用旧草稿覆盖新修订。

复制卡会带入参考与目标，但不继承确认、风险接受、锁定或结果。删除卡不删除样本。样本表展示参与卡片和用途，不再要求“已核对本行”。

操作区提供当前卡的保存、确认锁定、解除锁定、计算和结果入口。数量错误会在字段旁保留说明，并通过悬浮提醒提供定位；可以修正后重试，无需关闭阻塞式报错框。

## 最小人工复测

- 建两张吸附卡，各选相同的两个目标，分别用两组参考；分别确认和计算。
- 锁定 A 后编辑 B；检查 A 的状态和结果不变。切换和刷新检查 B 草稿恢复。
- 修改只被 A 引用的参考；影响列表只出现 A，确认后 B 的有效结果保留。
- 复制及删除卡；检查样本数量不变，副本未继承确认与结果。
- 把目标数量填为 0，在页面下部提交；检查提醒、字段错误和定位。改回有效正整数后继续。
- 在窄窗口滚动，确认当前卡解锁等操作可达，没有遮挡字段或横向挤压。
- 独立创建形成能分析，检查不能在同一分析混入吸附卡。

自动化证据覆盖修订冲突、服务端锁保护、旧记录迁移与公式数值，不要求用户重复所有接口用例。旧混合类型记录保留只读，通过明确按类型复制建立新的独立分析。
