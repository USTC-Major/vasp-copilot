## 已实现

- `/toolbox/postprocessing`：沿用科研工具主题与导航，多文件选择和文件建议。
- 原文件只读，上传独立副本，记录大小、SHA256、解析版本；持久化来源、结果、选择与参考配置。
- XML 总 DOS／已有 PDOS：元素、原子、轨道筛选后求和；非自旋与共线双通道。DOSCAR 目前只显示总 DOS，投影请使用 XML。
- XML＋原始 KPOINTS，或 EIGENVAL＋INCAR＋结构＋KPOINTS 能带；限倒空间 line-mode，匹配实际点数与坐标。普通网格和不匹配路径拒绝处理。
- 原始能量、文件费米能级、自定义参考；XML 能带按需解析也保留原文件费米值。EIGENVAL 缺参考时使用原始能量，不能冒称费米对齐。
- 后端保存筛选／参考／镜像／能带范围，切页和服务重启可恢复；视图更新检查 revision，防止旧页面覆盖。
- 单解析并发、独立进程、父进程 90 秒超时、子进程自身 95 秒截止、取消／失败及中断恢复。
- CSV／JSON 导出当前已保存曲线、来源与参考；CSV 明列分段编号，JSON 保留独立段。镜像只改显示，不将导出 DOS 变负；PNG 导出当前图形。
- 删除分析只删除副本；成功快照不再追加／替换输入，错误组合需重新导入。

## 当前 API（覆盖 PP-00 拟案细节）

基础路径 `/api/v1/toolbox/postprocessing/datasets`，使用 Toolbox envelope/error。首切片一份数据集对应一个分析。

| 方法 | 路径后缀 | 行为 |
|---|---|---|
| POST／GET | 空 | `{kind,title}` 建立 draft／列出分析 |
| PUT | `/{id}/files/{name}` | 原始请求体分块上传固定名称，流式计数 |
| POST | `/{id}/analyses` | 冻结输入、启动解析，返回 202 |
| GET | `/{id}` | 来源、状态、配置、摘要 |
| POST | `/{id}/cancel` | 取消本分析 |
| PATCH | `/{id}/view` | `{expected_revision,view}`；过期返回 409 |
| GET | `/{id}/curves` | 当前配置曲线；过大提示缩小范围 |
| GET | `/{id}/export?format=csv或json` | 当前曲线、来源和参考 |
| DELETE | `/{id}` | 删除非运行状态副本 |

与 PP-00 的 multipart 拟案不同：改用小 JSON 建记录＋原始请求体逐文件上传，避免 multipart 预缓存。状态位于现有 Toolbox 根的 `postprocessing/`，不新增凭据配置。PP-02 可复用此来源与结果层。

## 用户复测

1. 进入「结果后处理」，选择 DOS，导入 `vasprun.xml`；或用同次 `DOSCAR＋INCAR` 查看总 DOS。
2. XML 含投影时选择元素／原子／轨道，点击「保存并更新图形」。切换参考和镜像后保存。
3. 切页返回、刷新页面，从已保存列表重开，确认配置保留。未点击保存的配置不算已保存。
4. 下载 CSV／JSON／PNG，确认来源与参考可追溯，镜像不改数值符号。
5. 选择能带，用同次 `vasprun.xml＋KPOINTS`，检查标签、断段与能量参考；普通 Gamma 网格应被拒绝。
6. 窄窗口检查控件和长指纹；删除一份分析后确认原始文件仍在。

候选地址、中文路径样例及本机证据见内部回执。原始输出不可为消除提示而随意改写；需要补文件时重新建立分析。
