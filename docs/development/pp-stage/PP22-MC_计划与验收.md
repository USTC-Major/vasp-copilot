# PP22-MC：多计算卡计划与验收

日期：2026-10-11。基线 main `5433f49`（PR #64）；用户已批准 MC-01—03。实现、定向验证、独立审查与七项真实浏览器验收已完成；Git 合并及必需 CI 状态以本分支关联 PR 为准。不属于 v0.5.0 正式发布范围，不执行发布。

## 用户确认的行为

一份分析固定为吸附能或材料形成能，不混合类型。导入样本为共享池；用户可创建多张独立计算卡，自由选择参考与目标，同一样本可用于多卡。一张吸附能卡共用清洁表面与吸附物参考，多个目标分别填写数量 n，参考单元数 m 属于当前卡。形成能卡按已有公式配置元素参考及多个材料目标。

- 每卡独立保存、确认、锁定、解锁、计算与保存结果；无关卡不受影响。
- 左侧卡列表、右侧当前卡；切换和刷新保护草稿。当前卡操作区固定可达，窄屏不遮挡内容。
- 删除“已核对本行”和全局“纳入计算”语义，样本表显示参与卡及用途。异常状态的接受集中到当前卡确认，硬错误不能通过接受风险绕过。
- 数量或计量错误以非阻塞悬浮提醒、字段持续说明和定位动作反馈；定位到正确卡和字段，不能只在页面顶部显示。失焦或提交时校验，不在输入未完成时反复提醒。
- 修改共享样本前列出受影响卡，明确确认后以同一修订操作保存并使相关卡待确认；未引用该样本的卡不变。删除样本或清空继续保留数量和影响预览。
- 卡片复制保留配置但重置确认、锁和结果；删除卡保留样本。改名不改变科学有效性；单纯解锁不清空仍有效依据。
- 旧同类型单组或多组映射为卡；混合历史记录只读并显式按类型复制。读取不改写旧文件；首次写入有版本化原子迁移与可恢复原件。无法可靠验证的旧状态须重新确认，原始来源和内容保留。

来源解析、CSV、任务快照及吸附／形成公式沿用既有实现。此批不扩展能量模型、台阶图、磁矩模块或外部服务调用。

## 最小必要验收

1. 两张吸附能卡共享部分样本，各有多个目标；锁定 A 后修改 B，A 的有效结果保留。不要求 B 就绪才能计算 A。
2. 复制卡无确认／锁／结果，删除卡不删除样本；卡片自由分配、切换草稿与刷新恢复有效。形成能多卡与类型隔离成立。
3. 共享样本编辑／删除列出真实受影响卡，经确认只使这些卡失效；过期修订不产生部分修改，不能导出过期结果。
4. 风险集中确认、硬错误阻断、错误卡／目标／字段定位；数量修正后清除对应错误。宽窄屏固定操作可达，无横向布局损坏。
5. 旧单组、多组、混合记录读取与首次迁移保全原数据；样本 CSV 的原始值和人工覆盖依据仍可追溯。
6. 合成吸附能沿用 Pt4=-100、CO=-10、Pt4CO=-112/-111，结果为 -2/-1 eV；形成能 Al2O=-20、Al2=-8、O2=-10，结果为 -7 eV/化学式、-7/3 eV/原子。

后端针对状态、计量和迁移测试；前端针对卡片草稿、操作与错误映射；真实浏览器仅补跨层流程与布局。已有有效解析／CSV证据复用，不习惯性重复全量。真实模型、MP、SSH、HPC、VASP 科学结果不在验收范围。
