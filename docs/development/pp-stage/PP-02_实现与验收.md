# PP-02：任务结果接入实现与验收

日期：2026-10-10。开发基线：`ebf9c2b5286d5f3c19ccd67e25c8ac67a831411b`（PR #53 已合并主线）。本批分支：`feat/pp02-task-results`。适用范围见[开发合同](PP-02_任务结果接入合同.md)。

## 用户流程

1. 从计算任务的结果区进入“结果后处理”，或在后处理页面选择“已有任务结果”。明确项目、任务、计算步骤及当前提交尝试。
2. 点击预览，核对远端目录、可用文件、大小与推荐组合。预览只读取元数据，不下载结果正文。
3. 勾选文件并确认取回，观察下载进度；可取消或重试。整个组合完整取回后才形成可解析缓存。
4. 点击“解析缓存文件并查看图形”。分析使用现有 DOS／band 解析器，保留能窗、投影、能量参考、自动保存与导出。
5. 已缓存文件可以离线重开和重新解析。“刷新远端并新建分析”需要重新预览、确认并建立新快照，不覆盖旧分析。

下载完成与解析成功是两个独立状态。调度作业结束、取回成功、图形生成都不代表科学收敛；解析报告继续显示收敛和格式限制。

## 实现与接口

前端入口：`ToolboxResultsPanel` → `PostprocessingPage` → `TaskSourceImport`／`TaskSourceDetails`。后端复用 Toolbox 执行状态、SSH 连接和现有后处理 store／worker。

以下路由均位于 `/api/v1/toolbox/postprocessing`：

| 路由 | 行为 |
|---|---|
| `POST /task-sources/preview` | 接受四个来源 ID 和 DOS／band 类型；返回有期限的预览凭据、文件元数据、大小限制和建议组合 |
| `POST /task-sources/import` | 预览 ID＋确认文件列表启动下载；或仅传 `reuse_dataset_id` 核对并打开已有缓存，不连接 SSH |
| `POST /datasets/{id}/retry-download` | 重试已确认但未完整取回的组合；来源和预览仍须有效，否则重新预览 |
| `GET /datasets/{id}` | 返回独立的下载状态、进度和解析状态 |
| `POST /datasets/{id}/cancel` | 取消正在下载或解析的工作，不取消远端计算作业 |
| `POST /datasets/{id}/analyses` | 显式解析完整本地快照；沿用已有科学解析与资源限制 |

`source` 保存项目／任务／作业／尝试、提交记录、调度目标、远端目录、缓存时点及快照指纹；每个文件保存大小和 SHA-256。JSON／CSV 数据导出保留这些来源信息。

## 边界与限制

- 只取回已提交且处于 `completed`、`failed` 或 `not_converged` 终态的当前尝试，校验提交授权记录与目标。旧尝试的完整缓存可继续读取，但不会借旧 ID 读取远端新文件。
- 远端只读取七种固定科学文件名：`vasprun.xml`、`DOSCAR`、`EIGENVAL`、`KPOINTS`、`INCAR`、`POSCAR`、`CONTCAR`。禁止任意路径、链接及非普通文件；不提供整目录下载或 POTCAR／WAVECAR 取回。
- 原诊断下载的三文件权限和 32 MiB 上限保持原样；PP 使用独立 helper 操作与 64 MiB 单文件、128 MiB 单批、1 GiB 原始快照总量限制。下载前核对本地剩余空间。
- 预览有效期 15 分钟；单次结果传输预算 240 秒，最多同时取回两批。取消、失败、超时和重启中断不会留下可解析的半批数据；需要时由用户重新预览。
- 在取回前后核对整个选定组合与任务身份，分块读取核对文件身份和指纹。只能证明本次取回的目录与提交记录绑定，不能证明目录内每个文件一定由本次 VASP 运行生成。
- 支持矩阵沿用现有 PP：普通共线／非自旋 DOS、XML 原子／轨道 DOS 和普通路径能带；不新增 NCL／SOC、投影能带或压缩文件支持。

## 验收证据

本批使用隔离数据根、公开解析样例和假远端传输，不读取真实 SSH 凭据、不连接真实超算。后端边界测试与浏览器联调复用同一来源合同，浏览器通过真实 HTTP 请求进入 Toolbox 和独立解析 worker。

本地结果：

- 后端首次执行新增 `test_postprocessing_task_sources.py`、既有 `test_toolbox_results.py`，以及 `test_postprocessing.py` 的 `test_http_full_flow_and_upload_limits`、`test_recovery_and_cancel_without_killing_unrelated_process`、`test_source_change_prevents_worker_start`、`test_cancel_real_worker_is_scoped_to_analysis`：29 passed、4 skipped。Windows 不支持的 POSIX 实际 FD／链接用例由 Linux CI 执行。
- 审查修正后仅补跑相应小集合：磁盘空间、祖先身份及来源变化 4 passed；损坏帧／期限、跨任务同名缓存与受影响取消流程 9 passed。数目为各次执行结果，包含有原因的重跑，不代表互不重复的总用例数。
- 前端任务来源组件、页面、API、任务结果入口共 29 项相关测试通过。另经构建暴露的测试夹具类型问题已修正；最终 `npm run build` 成功。`npm run lint` 成功，已有 Fast Refresh 提示非阻断；新增组件导出工具函数产生的提示已通过拆分消除。
- 真实 Chromium＋HTTP：任务四 ID 预选；预览不传输正文；未勾选确认不能下载；确认后缓存但不自动解析；假远端设为离线后，公开 Al XML 仍经真实独立解析 worker 绘图、JSON 导出来源及指纹，页面重开不新增远端请求；390px 应用页面无横向溢出。未出现浏览器运行错误。
- 独立差异审查无未解决阻断。修正了下载前实际磁盘空间核对，以及过时 GET 响应覆盖重试状态、导致停止轮询的竞态。审查复用已有验证，不另跑重复测试。
- 新后端测试已加入 `remote-file-posix` 显式列表；最终提交的 `frontend`、`remote-file-posix`、`docker-smoke` 由 PR CI 核对后再合并。

本地测试解释器为项目 `.venv-pr-review` 的 Python 3.12.7；前端依赖复用同锁文件的隔离安装。浏览器证据保存在本机 `.tmp/pp02-evidence/`，其中 `browser-results.json`、`preview-wide.png`、`task-dos-wide.png`、`task-dos-narrow.png` 为本次运行产物，未纳入仓库或依赖用户私人计算数据。
