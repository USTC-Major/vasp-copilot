# PP 绘图简化与 v2 视图合同

本轮将后处理页面的坐标设置缩减为能量起点与终点，投影筛选改为元素、原子与轨道复选框，并在选择有效时自动保存。配置保存在独立分析快照中；绘图使用完整曲线，能量窗口只限制显示范围。

## 能量与绘图

- 新 DOS 分析以费米能级为参考，默认能量窗口为 `[-5, 3] eV`；新能带分析默认 `[-3, 2] eV`。费米能级缺失时后端使用原始能量，并给出缺失说明。
- 已保存记录的能量窗口继续使用原数值。旧坐标中的 DOS X 范围或能带 Y 范围迁移为 `energy_min_ev`、`energy_max_ev`。
- 页面只提供两个能量端点；所有刻度由 ECharts 自动设置。后端自动计算 DOS 纵轴，计算使用当前能量窗口内的全部已显示曲线及窗口边界插值。能带 X 范围严格对应完整 k 路径的两端，保留高对称点与路径分段。
- “完整能量范围”基于完整当前曲线的能量范围；参考能量正在修改时，前端将该范围换算到当前草稿参考。能带范围的草稿与已加载曲线不一致时，按钮暂不可用，直到该选择的曲线更新。
- 所有页面图形与 PNG 均固定白底深字，外围页面继续服从应用主题。DOS 保留悬浮信息；能带关闭悬浮、轴指针和系列响应。图形不再提供另一个会改变横轴窗口的缩放滑块。
- 沿用现有配色偏好与 PNG 尺寸／比例对话框。总 DOS 自旋沿用固定颜色槽；元素投影使用完整源元素顺序中的 `element_index`，过滤和重排不改变元素配色，同元素向下自旋以虚线区分。颜色数较少或元素较多时，颜色会循环使用。

## 能量参考

`pp.view.v2` 的 `custom` 表示相对费米能级的零点偏移 $\delta$，绘图能量为 $E-E_F-\delta$。页面标签为“相对费米能级的零点偏移 (eV)”；0 表示以费米能级为零点，+1 表示整图下移 1 eV。

| 记录／选项 | 实际减去的参考值 | 兼容行为 |
| --- | --- | --- |
| `raw` | 0 | 显示原始能量 |
| `fermi` | $E_F$ | 缺少费米能级时禁用 |
| 新 `custom` | $E_F+\delta$ | 缺少费米能级时禁用 |
| 有费米能级的旧 `custom` | 原绝对参考 | 偏移迁移为旧参考减去 $E_F$，图与窗口数值不变 |
| 缺费米能级的旧 `custom` | 原绝对参考 | 显式迁为 `legacy_absolute`，显示“旧版绝对参考”；该项只用于恢复旧记录 |

曲线响应的 `effective_reference_ev` 与兼容字段 `reference_ev` 都表示实际减数；视图中的 `reference_ev` 在新 custom 下表示相对偏移。不得将缺失费米能级当作零。

能量轴显示 `Energy E (eV)`、`E − EF (eV)` 或明确的偏移表达；DOS 轴为 `DOS (states/eV)`，不使用任意单位；路径轴为 `k path (Å⁻¹)`。响应的 `units` 同时保留总 DOS 每计算胞的归一化说明和投影求和单位。

## 投影选择

- 新记录最初只显示总 DOS。解析完成后，轨道默认勾选源文件实际提供的全部分量，元素最初均未勾选。
- 勾选某元素默认选中该元素全部原子，按元素分别生成投影曲线。展开原子后可逐个修改；部分原子选择时父元素半选，取消最后一个原子同时取消该元素。
- 存在部分元素选择时，`atoms` 保存所有已选元素中实际选择的原子编号，包括其他全选元素的原子；全选元素组合可用 `elements` 加空 `atoms` 简洁表示。
- `elements` 非空表示元素范围，`atoms` 非空表示精确原子范围，两者同时非空时取交集；`elements` 为空且 `atoms` 非空支持旧记录的独立原子筛选。
- 元素／原子全部取消，或轨道全部取消，都只显示总 DOS。空选择不会被重新解释为全部投影。
- 轨道只展示实际可用的 s／p／d／f 组及其源分量；群组与分量可以展开选择，父组支持半选。后端集合匹配避免群与分量重复计数。本轮没有引入晶体场分组。
- 原子超过 12 个时提供元素／编号搜索；搜索不会改变未显示原子的选择。
- 旧 `combined` 曲线保持恢复时的汇总含义；修改投影选择后按元素分别显示。旧空筛选中的“全部”在迁移时补为明确元素或轨道列表，以保留原图并消除空数组歧义。

## 自动保存与冲突

普通选择在下一事件循环自动排队；数字输入等待 400 ms。空值、未完成文本、非有限数值、反向范围或非法能带编号保留为草稿并显示说明，不发请求。

每个分析拥有单独的串行保存队列。保存使用 `expected_revision`，飞行中的操作完成后只推进该分析的版本；如果已有更新的草稿，旧成功响应不能覆盖草稿或切回旧图。组件按分析 ID 持续挂载，版本更新不会重新初始化控件。

切换分析或离开路由不会丢弃该会话内的合法待保存操作；队列继续处理自己的分析，重新打开时复用对应会话。失败和非法草稿保留在当前浏览器会话中。整页刷新或重新启动后，恢复的是后端已成功保存的配置。

遇到 CAS 冲突，或有草稿时收到包含外部不同设置的较新响应，自动保存暂停，当前草稿保留。继续编辑也不会静默覆盖外部设置。页面提供：

- **载入最新配置**：读取并恢复服务器上的当前设置，不写入。
- **重新应用当前选择**：说明会以本页完整选择覆盖最新设置，用户点击后重新读取版本并提交；再次冲突仍暂停。

普通网络失败提供“重试自动保存”。重试先读取服务器；若此前保存已经成功且与草稿一致，直接恢复成功状态；若发现不同外部设置，则转入上述冲突流程。

删除分析时才终止并移除其会话队列。查询缓存始终按响应所属 ID 写入，并拒绝较旧版本，因此 A 的迟到响应不能写入 B。

## 定向验证与边界

定向测试覆盖数字 debounce／空值／跨度溢出、飞行中的连续修改、显式冲突恢复与重应用、队列暂停后的零延迟定时器、外部 refetch 先于成功响应、切换分析、失败草稿重试、父子半选、空投影、原子搜索、旧参考迁移、稳定配色、白底绘图与 PNG 导出。生产构建和完整浏览器验收由独立审查统一执行到独立 dist；本轮实现不覆盖旧预览端口的共享 dist 或既有用户 state。

未接入真实 LLM、Materials Project、SSH 或 VASP 计算；此文描述后处理快照与合成测试验证的行为。
