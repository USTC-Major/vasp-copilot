# PP-22A 实现与验收

日期：2026-10-11。开发基线 `db73d613166b66ee290b1927104c19921f7298d3`，分支 `feat/pp22-basic-energy`。本文记录本批实现与本地验收，不代表正式发布；同提交 CI 和 Git 集成事实以本批 PR 的检查及合并记录为准。

## 实现

- 新增独立能量比较集、不可变来源快照和修订号，不改变 DOS／band 数据模型。
- 批量 OUTCAR、手填、UTF-8 CSV 和已有任务快照进入同一确认表；角色建议来自名称、相对目录及组成，仍需人工核对。
- 三种能量字段按同一完整离子块保存。组内统一字段，无隐式混用或缺值回退；原始值、人工覆盖、来源行和计算结果分开。
- 吸附多构型共享参考，校验完整组成及吸附物单元计量；材料形成能按元素参考原子数归一化。
- 输入、参考和计量变更使确认及结果失效；保存、重开、修订冲突、JSON／CSV 导出保留来源与风险。
- 运行中任务只通过能量专用读取策略取得稳定完整快照；原有 DOS／band 终态限制保持不变。快照保存执行尝试及来源身份，读取中变化或取消时不发布缓存。
- 结果区使用一份可展开的去重风险汇总，避免在总览、组和每个构型重复铺满相同提示。

接口见 [API 合同](PP-22A_API.md)，操作与人工复测见 [使用与复测](PP-22A_使用与复测.md)，正式范围见 [范围与验收](PP-22A_范围与验收.md)。

## 真实格式与模拟边界

三份许可明确、固定提交的 pymatgen 公开 OUTCAR 用于静态、弛豫、多步及三个不同能量字段的格式核查。当前锁定运行环境为 Python 3.12.7、pymatgen 2026.9.24／core 2026.10.2；三个独立能量值与该库全部一致。来源、SHA256 和 MIT 许可证见 [夹具说明](../../../backend/tests/fixtures/energy/README.md)。

公开 OUTCAR 夹具在 `.gitattributes` 设置 `-text`，防止 Windows 自动换行转换改变上游字节；暂存 Git blob 的三个 SHA256 已逐个与夹具清单核对一致。

PBE+U 元素映射、吸附／形成能算例、异常输入、任务身份与传输协议使用明确标识的合成数据或替身。没有验证真实吸附能、参考态适用性、参数收敛、真实模型、MP、SSH、HPC 或 VASP 计算。

OpenAPI 由既有官方脚本完整导出一次。基线文件遗漏的既有路由与新增同名模型引起的限定组件名也随生成刷新；不是另行实现旧模块。生成环境 FastAPI 0.141.1／Pydantic 2.13.5 满足依赖下界，与 Windows 锁定版本不同，已核对本地引用完整且没有个人配置值。

## 限制与后续

自动比较首版限定于元数据充分的普通 PBE／PBE+U SCF 静态或弛豫。其他方法、非 SCF、MD、响应／GW、NCL／SOC 等不会因能读出标量而自动开放；未知或未收敛状态与硬错误分开处理。人工来源可显式纳入，但保留未知方法和收敛风险。

64 MiB／OUTCAR、128 MiB／比较集、100 样本，能量缓存独立 1 GiB，CSV 最多 1 MiB。近限额行为由专门断言验证。正式发布、真实超算取回及真实科研算例验证未在本次授权中。

本批收口后建议先由用户复测基本能量工作流，再确定 PP-06 催化台阶图或 PP-11 修正项的下一切片；PP-M 仍后置。建议不等于已启动下一阶段。
