# 后处理图形切换去闪

用户在 13683 预览中反馈：同一分析切换投影或其他绘图设置时，图形会短暂闪一下。

## 原因与证据

自动保存成功后，曲线查询的 key 随分析版本变化。原页面在新查询 `isPending` 时只渲染加载图标，因此卸载整张 `Plot`。`echarts-for-react` 的 `componentWillUnmount` 调用 `dispose`；新数据到达后又初始化图表。430 px 的图在两次请求之间消失，造成白屏和页面高度变化。

这不是绘图动画：图形原本已设置 `animation: false`。封装组件的普通 option 更新会调用原实例的 `setOption`，无需重新创建实例。

新增慢请求回归先在旧实现失败：保存成功、曲线 GET 等待时找不到图表 DOM。修复后，等待和更新前后是同一个 DOM，挂载一次、无卸载。

## 最小修复

- 每个已挂载的分析组件只保留自己的最后成功曲线。下一版本请求等待或失败时，继续显示该已应用图；新数据就绪后原位更新。
- 分析仍按 dataset ID 挂载。切换 dataset 时清除旧图实例，加载区域保留固定高度；不将 A 的曲线当作 B 的图。
- 继续使用原查询 key、自动保存队列与 CAS；没有引入新缓存层或修改后端。最后曲线保护同时核对 ID 和版本，旧响应不能覆盖较新已应用图。
- 图表 option 只随曲线或配色变化重新生成。保留 `notMerge` 原位更新，以正确删除取消的投影系列。
- 等待时显示“正在更新，当前显示上次已应用配置”；失败时保留图并提供原重试入口。错误提示位于图后，避免把图向下推移。
- 所有导出在保存等待、曲线等待、失败／冲突或当前选择尚未应用时暂停。只有当前选择、已保存版本和已应用图一致时重新启用，防止按 ID 导出的最新服务器配置与保留图不一致；PNG 导出回调也验证就绪状态。

## 验证与交付

定向回归覆盖慢 PATCH 与慢曲线 GET 两个阶段、等待期间实例和图保留、失败重试、旧响应迟到、不同 dataset 切换、取消投影系列以及导出暂停／恢复。另复测原保存队列、物理绘图和 PNG 对话框测试。实际浏览器验收由独立 review 使用隔离构建执行。
