> 后续实施：首个本地闭环已形成候选，实际 API、范围与待办见 [PP-01／03／04 回执](PP-01_本地绘图候选与复测.md)。本文接口为实施前拟案。

日期：2026-10-10。基线 `fbcbebcf8dd72df50a5fb2a0537b14f45759d84e`；分支 `feat/pp00-postprocessing-contract`。本轮为调查、离线探针和合同，产品实现从下一个切片开始。所有路由和字段均为拟实施合同，不是当前已存在接口。

## 1. 结论与复用决策

先做本地 DOS／能带读取与交互绘图。沿用已依赖的 pymatgen、NumPy、ECharts，不新增大框架或要求用户安装 VASPKIT。有限的 DOSCAR 格式适配可单列实现；复杂投影、自旋与体数据处理优先成熟库。决定依据是实现、参考样例、内存、平台兼容和长期维护的总成本，不按 VASPKIT 是否有同名菜单机械划分。

| 工作 | 决策 | 相对成本／原因 |
|---|---|---|
| XML DOS、PDOS、能带 | 复用 `pymatgen.io.vasp.outputs.Vasprun`；禁止自动寻找 POTCAR | 中：已完成数值读取探针，但仍需尺寸、完整性、自旋与来源校验 |
| EIGENVAL | 复用 `Eigenval`，外围校验声明／实际 k 点和能带数量 | 中：发现截断文件可被库部分补零；库读取成功不是完整性证明 |
| DOSCAR | 独立 VASP `Doscar` 类在实测两个 pymatgen 版本中均不存在；首发可实现受限格式适配 | 中：固定支持 3／5 列总 DOS；常见 LORBIT=10／11 投影布局按证据验证。不能复用 LOBSTER DOSCAR 类冒充 VASP 格式 |
| 绘图 | 复用 ECharts／React 组件与现有主题；数值变换归共用分析层 | 低至中：已有诊断图表经验；数据选择、能量参考和保存是新增工作 |
| 结构测量／对比 | pymatgen 周期几何＋已有结构视图 | 中：查看器是 SVG 原子／晶胞视图，能复用交互习惯；复杂自动原子映射暂缓 |
| 催化台阶图 | 先表格、相对能量和路径显示；后续接任务来源 | 低至中；不自研通用热化学引擎，修正值可导入或复用工具 |
| 电荷显示 | `Chgcar` 读取已有数据；三维等值面组件另评估 | 中至高：现有 SVG 结构图不是体渲染器；需性能与依赖验证 |
| 有限差分 | 同晶胞、同网格、确认构型后的 NumPy 线性组合 | 运算低、完整链路中；复用 PP-07 输入，暂不做跨网格插值和自动配准 |
| NCL／SOC | 后续复用已有解析，单独验证磁化分量和坐标依据 | 中至高且样例未齐；首批明确识别并拒绝未支持模式 |
| 任务结果取回 | 扩展现有固定文件协议，保留来源与尝试验证 | 中至高；当前仅三种文件、32 MiB，不能只给前端新增一个下载按钮 |

成本等级是范围比较，不是工期承诺。无需为 XML 核心路线升级当前发布依赖；3.11—3.14 的完整兼容仍在后续 CI 核验，不将本次单台 3.12 实测泛化。

## 3. 首个实现切片与输入支持

建议交付切片：PP-01 最小本地数据集＋PP-03 基础 DOS／PDOS＋PP-04 普通能带。先本地浏览器文件选择／多文件导入，不新增任意路径读取 API。目录导入只选择与展示必要文件，后端逐项校验；本地和任务来源以后转换为同一不可变数据集。

| 输入 | 首个切片目标 | 判定与失败行为 |
|---|---|---|
| `vasprun.xml` | 总 DOS、已有 PDOS、实际能量／k 点；优先主路径 | `parse_potcar_file=False`、按需启用解析、严格 XML 完整性；不读同目录 POTCAR |
| `DOSCAR`＋元数据 | 总 DOS 与受限的共线投影适配 | 总 DOS 3／5 列；投影仅明确 ISPIN、LORBIT 和元素对应的受测布局；NCL／未知布局明确不支持 |
| `EIGENVAL`＋结构＋原始 `KPOINTS`＋模式信息 | 普通 line-mode 路径能带 | 必须核对 k 点、分段、基矢和样本次序；普通 Gamma／Monkhorst 网格不冒充高对称能带 |
| XML 能带＋原始 `KPOINTS` 或可确认路径元数据 | 路径能带与已有标签 | 仅 XML 有特征值而无可靠分段，不猜一条新路径；提示补数据 |
| `INCAR`／`OUTCAR`／结构 | 按需补充自旋、结构、能量参考和计算状态 | 输出与输入冲突时以证据说明冲突；不自动选择“看起来合理”的值 |
| 已处理数据表 | 预留中立数组接口；准确 VASPKIT 表格式后续单独适配 | 不用文件名判断能量是否已对齐，避免重复减费米能级 |

原始输入第一切片先支持普通未压缩文件。探针中 `.gz` 为上游样例的存储形式，不等于产品已支持压缩导入；压缩支持要有解压后体积限制。首个切片不要求 POTCAR／WAVECAR、不解析任意 ZIP，也不重算 DOS 或波函数。

DOSCAR 实现门槛：单／双自旋、全部投影块计数、每块 NEDOS 与能量网格、有限数、索引顺序和文件完整性均需固定参考。若投影支持未达标，可先开放总 DOS 和 XML PDOS，并将 DOSCAR PDOS 标为未交付，不能当成整个 PP-03 已完成。

## 4. 中立数据合同 v1

所有数值为有限数；缺失使用显式 null／状态，禁止 NaN、Infinity 或静默补零。持久化数据不依赖当前页面和模型会话。

### 4.1 数据集与来源

- `schema_version`: `pp.v1`；`dataset_id`: 服务端生成不可猜混淆的身份；`revision`: 单调版本。
- `source.kind`: `local_upload` 或后续 `task_result`。后者必须记录 `project_id/task_id/job_key/attempt_id/submission_action_id`，不只保存路径。
- `files`: 每份文件包含 `file_id/role/name/size_bytes/sha256`；本地完整路径不作公开下载地址，任务远端来源仅在相应权限下展示。
- `parser`: 库名、库版本、适配器版本；`completeness`: `complete/incomplete/unknown`；`convergence`: 单独的 `converged/not_converged/unknown`。
- `spin_mode`: `non_spin/collinear/noncollinear/unknown`；`soc`: `true/false/null`；`evidence`: 支持上述判断的字段来源。
- `warnings`: 结构化 code、说明和缺少的材料；能量参考缺失与模式不支持不混成普通服务器错误。
- `analysis`: 类型、选定通道／投影／路径、参考能量与来源、数据归一化、绘图配置；输入快照不随保存图形配置改变。

### 4.2 DOS

- `energies_ev`: 未重复平移的能量网格，严格递增；`total`: `total` 或 `up/down` 密度数组。
- `projected`: 按原子 ID、元素、已确认轨道标签和通道索引的密度，不依赖前端猜列数。
- `density_unit`: 明确每胞／每原子；积分 DOS 使用独立字段及单位，不混进密度曲线。
- `energy_reference`: 数值、来源文件／用户指定、`already_shifted` 与当前显示变换。向下自旋镜像仅是图形配置，导出原始密度不变负。

### 4.3 能带

- `kpoints_fractional`、带有 `2π` 约定的倒格矢基底及沿每段的实际距离；横轴单位明确为逆 Å。
- `segments`: 起止样本索引、端点标签（可空）、断开标志；不能跨断点强行连线。
- `bands_ev`: 通道 × k 点 × band 的固定形状；占据数另存；声明尺寸必须等于实际读入。
- `energy_reference`: 与 DOS 相同语义。缺可信费米能级时可选择明确标记的原始能量或用户参考，不能默认 0 就叫费米对齐。
- 线性插值只用于视觉连接，不凭此计算未采样带隙；带隙等派生指标属于后续能力。

### 4.4 拟议操作边界

| 操作 | 请求／响应约定 |
|---|---|
| `POST /api/v1/toolbox/postprocessing/datasets` | multipart 有界上传；元数据指定分析意图和文件角色；返回已落盘数据集摘要，未解析完成不冒称 ready |
| `GET .../datasets/{id}` | 来源、状态、缺项、支持能力；使用 Toolbox 的 envelope/error 约定 |
| `POST .../datasets/{id}/analyses` | 选定类型与数值参数；返回 `analysis_id` 与状态，解析在工作线程／进程完成，不阻塞请求循环 |
| `GET .../analyses/{id}` | 结果元数据、可用通道、错误和警告；大数组按范围分块读取 |
| `PATCH .../analyses/{id}/view` | 仅更新视图配置；带 expected_revision，过期修改返回冲突，防止旧页面覆盖 |
| `GET .../analyses/{id}/export` | 从同一数值快照生成 CSV／JSON 与来源说明；首批 PNG 可用图表导出，标注相同参考与配置 |

取消、删除、列表恢复和缓存清理接口在 PP-01 实现设计中补齐，保持相同数据生命周期，不通过刷新页面丢弃后台作业。物理目录建议位于现有 Toolbox 数据根的 `postprocessing` 子目录，不新建配置或凭据系统。

候选工程限制：未压缩单文件 64 MiB、单批 128 MiB、归一化结果 200 万标量、单次图形数组响应 5 万标量；作为实现起点，压测后可收紧。输入限制必须流式计数，不能先 `read()` 完再拒绝。实际内存不等于原文件大小；解析超时、并发与内存预算需按发布环境实测，PP-00 不宣称已经实现硬限制。首个切片不得无提示截断科学数组；超限说明原因，图形抽样只改变显示。

## 5. N 系列与队友改动的衔接

- N17—N19：项目根目录和目录创建不是本地绘图的前置。PP-02 使用已确认任务来源，可先利用现有工作区；目录规范化后仍保留历史文件快照。修改入口时协调 DT-02，核心解析无需等 B。
- N16：模板可为文件建议提供步骤类型，但不能仅按步骤名推断数据身份或模式。
- N23—N25：后处理绑定精确 attempt。重试产生新数据集，不更新旧图的源文件；无自动执行能力时仍能分析已有结果。
- N08／N09：复用证据与样式，不改变诊断规则。PP-13 的 NCL 图形支持不自动扩大磁矩诊断的科学范围。
- N12：每个稳定小闭环提供简短操作说明，供 A-4 最后整理，不等待整个 PP 系列完成。

## 6. 实施验收门槛

实现按小切片提交，先独立数值适配和失败用例，再 API／持久化，再界面。至少包含：非自旋／共线 XML、受限 DOSCAR、完整／截断 EIGENVAL、缺参考、普通 k 网格误用、断段路径、NCL／SOC 拒绝、同名不同任务、中文路径、切页恢复和可核对导出。

现有探针证明“可复用”和已知风险，不替代生产完整性、API、浏览器或全平台验收。下一切片可从已验证的 XML 路线开始，同时补非自旋极化 XML、真实路径标签和 DOSCAR 独立参考；这些缺口阻塞对应模式的完成声明，不阻塞已验证路线的实现。

科学格式依据：[pymatgen VASP I/O](https://pymatgen.org/pymatgen.io.vasp.html)、[VASP DOSCAR](https://vasp.at/wiki/DOSCAR)、[VASP EIGENVAL](https://vasp.at/wiki/EIGENVAL)。软件接口以本次发布环境实测为准，网页文档不能替代实际锁版本。
