# PP-01：坐标、图表交互与 PNG 改进候选

日期：2026-10-10；工作树 `.tmp/pp00-postprocessing`，分支 `feat/pp00-postprocessing-contract`。这是用户已批准的候选增量，保留 PP-00／PP-01 的原有未提交实现，不代表已创建 PR、合并或发布。

## 批准范围与行为

- DOS／band 的 X、Y 轴起点、终点和刻度间隔可编辑并随分析保存。第一次解析或旧分析迁移时按当时曲线确定范围；此后切换投影、参考、镜像和能带选择都保留原坐标数值。
- 「按当前数据适配范围」使用当前待保存参考、投影、镜像和带数；返回的轴配置仍是草稿，点击「保存并更新图形」后生效。
- 范围外曲线给出提示；轴限值和缩放不裁剪科学数组。CSV 的镜像密度符号保持原有语义，JSON 额外包含保存的坐标配置。
- 起点须小于终点，间隔为正有限数；每轴最多 200 个刻度间隔。前端可见校验和后端校验共同拒绝不合法配置。
- band 关闭悬浮数值框、轴跟随线和曲线悬浮交互；保留数值刻度、实际分段和固定高对称点辅助标记。DOS 保留悬浮提示。
- 原子选择宽屏先显示六个标签、窄屏三个，余项显示「另 N 个」；显式展开后全部标签换行。
- PNG 采用指定宽高的独立 ECharts 画布重绘，白底深字，无 zoom 滑条或操作控件。目标尺寸与图形坐标范围相互独立；输出宽高各 240–8000 像素、每张最多 3200 万像素。
- 图例和曲线共享同一颜色；上下自旋保持实／虚线区别。DOS 总量、所选投影和自旋采用固定语义颜色位置，排序、筛选或能带数量不会改变同一语义曲线颜色。

## 数据与接口合同

保留 `pp.v1` 数据集和科学结果格式，在已版本化 `view` 中加入 `axes`：

```json
{
  "version": "pp.axes.v1",
  "x_min": -10,
  "x_max": 10,
  "x_interval": 2,
  "y_min": 0,
  "y_max": 20,
  "y_interval": 5
}
```

`PATCH /api/v1/toolbox/postprocessing/datasets/{id}/view` 仍使用 `expected_revision`。旧客户端省略 `axes` 时保留现有轴配置；显式空值或不受支持版本拒绝保存。旧 ready 记录缺少坐标时，在同一 store 锁内从已有结果确定并原子保存一次，revision 增加一次。重复读、并发读和服务重启不会再次初始化；迁移前版本保存明确返回 409，原始文件、已有筛选和解析数组保留。

新增 `POST .../datasets/{id}/fit-axes`，请求 `{expected_revision, view}`，使用完整待应用选择。此接口只计算并返回 `{axes,revision}`，不更新持久数据；过期版本同样返回 409。前端调用时省略草稿中的 `axes`，使适配能修复尚未填完整的输入框。

曲线响应新增稳定 `id`：`dos.total.{channel}`、`dos.projection.{channel}`、`band.{channel}.{band_number}`。band 各段仍独立，并保留 `segment_index` 和原高对称点标签。新增 `plot_warnings` 提示当前显示超出保存范围。

图形共用 `buildPlotOption(data,colors,theme,output?)`；PNG 工具为 `exportPostprocessingPng(data,{width,height,colors})`。独立 `PlotExportDialog` 传递 `{width_px,height_px,colors}`，预览与下载均通过同一重绘函数；临时导出配色与全局默认由独立偏好模块区分，仅显式设为默认才写偏好。
