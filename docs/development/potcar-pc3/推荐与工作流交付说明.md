# POTCAR 推荐与工作流接入（PC-R1 至 PC-4）

本阶段在已有本地 PAW-PBE 库管理和独立拼接上，增加有依据的有限推荐、手动刷新说明及工作流 ZIP 接入。尚未合并或发布，不替换桌面 EXE。真实赝势不随仓库或制品分发，不通过 VASPKIT 生成，不由 AI 选择或拼接。

## 使用流程

1. 在本地赝势库页面登记自己的授权库。“刷新赝势库”重新扫描本地文件并更新索引；“重新读取库列表”只读取已有记录。文件增删改后需主动刷新，不会联网下载或自动改库。
2. 独立拼接页可指定普通／特殊用途、PBE／PBE+U／HSE06 和已知条件。未知条件保持未知。工作流则从服务端保存计划的最终 POSCAR、全部步骤及实际组合参数推导上下文，不接受客户端另传一份结构作为证明。
3. 工作流计划页默认“不包含，后续自行补齐”。选择“从本地库包含 POTCAR”，读取预览，核对物种顺序、候选来源和建议。改选后刷新预览；手动选择不会被规则替换。
4. 核对后确认一次，准备不可变 POTCAR 产物并关联列出的全部步骤；再生成工作流文件、下载 ZIP。每个步骤保留相同数据集和物种顺序。
5. 改参数、结构、用途、规则或计划版本后需重新预览确认。源文件或索引变化时按提示刷新库；包含失败不会悄悄变成缺 POTCAR 的成功包。

## 首批推荐范围与依据

规则包 `paw-pbe-selection-r1`。普通用途的有限元素通则覆盖 B/C/N/O/F 的常规势、Ga/Ge/In/Sn 的 `_d`、Li 及 Rb/Sr/Cs/Ba 的 `_sv`。依据为 [VASP 官方选择说明](https://vasp.at/wiki/index.php?title=Choosing_pseudopotentials&oldid=38073)；[可用数据集与后缀](https://vasp.at/wiki/index.php?title=Available_pseudopotentials&oldid=25069)用于解释候选与版本差别。

推荐项缺失、多个来源、规则冲突或信息不足时转人工选择；不会按 ENMAX 或后缀排一个统一优先级。Be/Mg/K/Ca/At 的来源差异保留人工核对。磁性、短键、高压和高空态需求只在显式条件成立时提示；不从结构猜基态、价态或压力。HSE06 不自动选择软势 `_s`，明确手选仍保留并显示警示。PBE+U 不等于选择 `_d`，不自动改 U/J。

库发布版本未知：TITEL 日期和自由备注不作为发布版认证；本轮不启用 `.64` 完整默认表。建议具有来源、规则版本及适用条件，不能代替收敛测试或科学判断。

## 接口与失败恢复

- 共享 `POST /api/v1/toolbox/potcar/previews` 增加可选 `context`，缺省为未知；返回 `selection_reason`、独立 `advice`、`rule_sources`、`rule_version` 与可选 `workflow_binding`。原确认及专用下载接口兼容。
- 工作流配置 `potcar={mode:"omit"|"include",artifact_id?:string}` 默认 omit。`POST /workflows/plan` 支持基于 `workflow_id` 重放并更新显式 patches／potcar，递增 revision；预览前先保存当前参数。
- `POST /workflows/{id}/potcar/preview` 接受 revision、library_id、index_revision 及可选 dataset_ids；绑定最终 POSCAR、完整请求、实际步骤参数和规则版本。
- 首次产物发布校验当前计划，计划变化或过期阻止旧预览新物化。已经成功生成的专用快照仍按原 24 小时寿命下载；旧 PC-2 产物可下载，但不能充当新工作流绑定。
- 状态区分未包含／待补齐、待确认、生成中、已生成、失败。逐步骤状态、报告、清单和文件树依据实际结果；只解除已具备文件的 POTCAR 阻断，上游输出与诊断条件仍独立成立。
- 生成与重规划的最终发布使用短锁和尝试标识；旧请求不能发布旧 ZIP 或清掉更新的成功结果。Toolbox 接收中立验证／发布接口，不导入应用内部对象。
- POTCAR 正文不注册通用 FileStore、不提供普通预览，不进入 AI、日志或错误响应。正文仅通过专用下载或用户确认的工作流 ZIP 交付。

## 验证与限制

自动化使用合成数据覆盖有限规则正反例、缺目标／冲突／同名来源、手选与上下文失效、旧产物兼容、最终结构绑定、重复及零数量物种、static/band 字节一致、门控／报告／清单、失败恢复和并发发布。CI 显式运行并核对 `test_potcar_recommendations` 与 `test_workflow_potcar` 模块，避免仅收集而未执行。

本地相关后端回归 453 项通过，Windows 无符号链接权限的 1 项明确跳过；独立审查的 6 项绑定与并发边界回归通过。真实后端与生产前端已完成合成三步骤页面生成和下载，ZIP 各份 POTCAR 与专用产物逐字节一致，其他门控保留。最终同提交 CI、真实授权库受控核验及用户复测结果以 PR 回执为准。

现有工作流仅 relax/static/dos/band；是否开放 band 沿用现有开关。没有新增 HSE 或压力工作流，相关上下文适配仅以组合参数单测验证，独立 HSE06 规则单独覆盖。DFT+U 仍按元素唯一条目，不能表达同元素不同块的不同 U；工作流仍要求具名 POSCAR，独立旧格式显式映射保留。未运行真实 VASP 或证明科学收敛性。
