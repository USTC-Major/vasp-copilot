# VASP-Copilot v0.4.1

v0.4.1 主要改进 Windows 桌面的 Python 识别与启动兼容，解决部分电脑已安装 Python、程序仍无法启动的问题。

## 本次更新

- **支持 Python 3.11–3.14：** 新增标准 Windows x64 Python 3.13/3.14 的完整应用依赖支持，首次自动准备，后续复用。
- **自动发现更完整：** 检查 PATH、注册信息、常见安装目录与 Conda 登记环境，支持中文和空格路径。
- **启动设置更清楚：** “自动检测”可清除失效的手动路径，设置页显示上次使用的 Python 版本与位置；识别失败时给出具体原因。

工作流、诊断、智能模式、任务工具和本地授权赝势库功能延续 v0.4.0，文件写入及计算提交仍按现有流程确认。

## 下载与升级

- [Windows 完整桌面包](https://github.com/USTC-Major/vasp-copilot/releases/download/v0.4.1/vasp-copilot-0.4.1-windows-x64.zip)
- [源码包](https://github.com/USTC-Major/vasp-copilot/releases/download/v0.4.1/vasp-copilot-0.4.1-source.zip)
- [快速开始与升级说明](https://github.com/USTC-Major/vasp-copilot/blob/v0.4.1/0.4.1快速开始.md)

退出旧桌面，将新包完整解压到新目录，双击根目录 `启动完整功能.cmd`。在启动设置中选中**新包根目录**，Python 点击“自动检测”后保存并启动；不要沿用旧安装目录或只复制 EXE。

需要已有 Windows x64、标准 CPython 3.11–3.14 x64、.NET Framework 4.8 和 WebView2 Runtime。桌面包无需 Node/npm；首次依赖安装需要直连官方 PyPI，不修改基础 Python 环境。

## 已知限制

**Python 3.15 暂不支持完整应用。** PyYAML、pymatgen-core、spglib 等关键依赖尚缺相应 Windows 二进制安装包；程序会识别并提示原因。32 位、ARM64、自由线程及预发布解释器未纳入本版支持。

本版不捆绑 Python 或真实赝势，不新增表面模型、完整自动连续执行等规划中的功能。其他范围及验证边界见[发布说明](https://github.com/USTC-Major/vasp-copilot/blob/v0.4.1/docs/release/v0.4.1/发布范围与验收说明.md)。附件 `SHA256SUMS.txt` 可用于校验下载，`release-provenance.json` 记录对应代码与构建来源。
