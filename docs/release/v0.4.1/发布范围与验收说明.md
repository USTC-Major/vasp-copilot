# v0.4.1 发布范围与验收说明

日期：2026-10-09。本版通过 PR #52 交付桌面 Python 兼容修复，其他业务功能范围沿用 [v0.4.0](../v0.4.0/发布范围与验收说明.md)。

## 兼容范围

- Windows x64、标准 CPython 正式版 3.11/3.12/3.13/3.14；每个版本使用独立的精确依赖及哈希锁。
- 自动发现已有解释器，首次在应用专用目录准备依赖；不安装系统 Python、不修改用户基础环境。
- 3.15 可识别但因关键 wheel 缺失而拒绝完整运行。32 位、ARM64、自由线程、预发布及未知未来版本未纳入支持。
- 支持中文/空格目录；自动搜索包括 PATH、注册信息、常见目录及 Conda 登记，不承诺找到任意未登记的自定义路径，仍保留手动选择。

## 发布门槛与证据

- 最终 PR 提交必须通过四版本 Windows、frontend、remote-file-posix 和 docker-smoke 共七项 CI。
- Windows 验证涵盖干净构建、锁定依赖首次安装与复用、控制器、自动发现及真实本地三服务、核心应用合成数据回归。
- 本地另验证真实 3.13/3.14 中文目录安装、离线复用与服务退出；两版核心应用各 83 项通过、1 项因符号链接权限跳过。3.15 RC 仅检查拒绝行为。
- 合并树须与已测 PR 树一致；正式构建核对源文件、EXE、生产前端和包内外 SHA256，并下载核对 Release 附件。
- 用户授权审核通过后直接发布，免除本轮用户手工复测；不声称原故障设备或全新机器已验收。

发布代码 SHA、最终 CI 链接与构建摘要见 Release 附件 `release-provenance.json`；这份说明列出范围，不代替附件中的实际结果。

## 保留的限制

- Python、.NET 4.8、WebView2 仍需预先具备；首次安装依赖需官方 PyPI 直连，暂不继承代理。
- 升级时须手动选择新解压根目录；不会自动迁移旧安装路径。
- 不新增真实模型、MP、SSH/HPC 或 VASP 科学结果验收；软件测试不代表科学计算正确。
- 不分发真实赝势，继续禁止 VASPKIT 生成或拼接 POTCAR。双端项目目录初始化、完整 A-4 指引、表面/吸附、振动/声子、反折叠、VASPKIT Skill 和完整自动执行仍在后续规划中。
