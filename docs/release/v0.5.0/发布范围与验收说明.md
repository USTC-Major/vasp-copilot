# v0.5.0 发布范围与验收说明

日期：2026-10-10。本版主题为结果后处理与桌面体验更新；原工作流、诊断、基础任务与本地授权赝势库能力延续前版。

## 已实现范围

| 范围 | 本版行为 |
|---|---|
| 本地结果 | 导入指定原始 VASP 文件，保存独立副本，解析、保存与重新打开分析 |
| 任务结果 | 绑定项目／任务／作业／执行尝试，预览元数据与大小，确认取回后形成完整本地快照；离线重开与显式刷新新快照 |
| DOS／PDOS | 非自旋与普通共线总 DOS；`vasprun.xml` 中已有的原子／轨道 PDOS，可按元素、原子与轨道选择 |
| 常规能带 | XML 或 EIGENVAL 路线，核对同次倒空间 line-mode KPOINTS 与实际采样，保留路径分段 |
| 图形与数据 | 能量窗、费米参考／相对偏移、自动 DOS 坐标与刻度、设置自动保存；白底 PNG、CSV、JSON 和默认配色 |
| 桌面启动 | 根目录 `VASP-Copilot.exe` 单入口，自动端口与 Python 检测，独立锁定依赖环境，设置保存与重开恢复 |
| 设置与升级 | 统一设置中心、重启影响确认、已知旧启动配置兼容、可确认的旧数据根保留、冲突与不确定路径提示 |

AI 是可选客户端；以上确定性基础能力不依赖模型配置或 AI 服务可用。远端结果取回仍需要自己的 SSH／站点环境，本地缓存解析不需要超算连接。

## 文件与科学边界

- 仅支持未压缩的 `vasprun.xml`、`DOSCAR`、`EIGENVAL`、`INCAR`、`KPOINTS`、`POSCAR`、`CONTCAR`；不提供任意目录或 ZIP 导入。
- DOSCAR 当前仅展示总 DOS，PDOS 需 XML 中实际包含投影。普通 k 网格、笛卡尔 line-mode 或混合 k 网格不属于本版路径能带支持范围。
- 缺少可信费米能级时明确使用原始能量，不能新建费米参考或相对偏移；保留旧记录的参考语义，不悄悄改变原图。
- 单文件最多 64 MiB、单批最多 128 MiB，原始快照总缓存上限 1 GiB；归一化结果最多 200 万数值。超限、缺项、截断、来源变化与不支持模式明确提示，不截断数组冒充完整结果。
- 任务新取回限于有可信提交记录、处于 `completed`、`failed` 或 `not_converged` 终态的当前尝试。只取回支持文件，不包括 POTCAR、WAVECAR 或整个目录。
- 预览只读元数据，确认后才下载；文件与来源变化、链接、取消或中断不会提交为可解析的完整缓存。重开旧缓存不代表已核对远端最新状态。
- CSV／JSON 保留来源与文件指纹；哈希证明字节一致，不能证明文件确由本次作业生成或结果已科学收敛。图形变换不改写原始数值。

## 桌面兼容与升级

- Windows x64、标准 CPython 正式版 3.11/3.12/3.13/3.14；沿用既有支持政策、独立精确依赖及哈希锁，本版不升级依赖。
- 已有 .NET Framework 4.8 和 WebView2 Runtime；不捆绑系统 Python 或安装器，运行桌面包无需 Node/npm。
- 首次专用依赖准备直连官方 PyPI，不继承代理或用户 pip 源。3.15 暂缺关键 Windows 二进制依赖；32 位、ARM64、自由线程、预发布及未知未来解释器未纳入支持。
- 新包完整解压到新目录，从根 EXE 启动；旧实例先退出。保存目录指向另一包时提示核对，阻止混用前后端。
- 正式启动偏好位于 `%LOCALAPPDATA%/VASP-Copilot/desktop/preferences.json`，已有新配置优先；旧来源内容不同时由用户明确选择，原件保留。
- 迁移仅在可靠确认后保留原实际数据根，含旧完整模式默认路径与可解释的旧环境配置。动态路径、旧目录不可访问等无法确认时停止并说明，不假定无条件自动迁移，不搬动数据库、凭据或科研文件。
- 工作流草稿只在当前应用会话切页后恢复；服务重启／页面刷新前需保留必要内容。后处理成功保存的分析与图形配置可重开，未保存修改另有提示。

## 验收依据与正式记录

本版功能复用已完成的后处理与桌面验证：公开／合成数据的本地导入、独立解析与真实浏览器绘图；任务来源、确认取回、缓存离线重开及数据导出；桌面实际包的设置保存、进程重开恢复、旧数据根保留和设置中心兼容。此前桌面两次集成 PR 的七项 CI 与完整包后处理交叉检查已通过，用户在本轮明确确认复测通过。

**上述记录证明对应实现与当时受控场景，不替代 v0.5.0 正式提交及最终附件的验证。** 正式发布记录需关联实际代码 SHA、四版本 Windows、frontend、remote-file-posix、docker-smoke 七项 CI，以及最终构建、包清单与下载校验；实际结果与链接统一见 Release 附件 `release-provenance.json`。本说明不预先声称尚未记录的正式 CI 或包检查已通过。

此前专项详细证据保留在[后处理开发入口](../../development/pp-stage/README.md)及[桌面构建说明](../../../desktop/README.md)。历史回执中的候选、未提交与未发布状态只描述当时，不作为本版当前状态。

验证主要针对受控软件行为与公开／合成科学文件；假远端传输不能代替真实 SSH/HPC 站点兼容，软件测试不能代替真实模型质量、所有体系或 VASP 科学结果验收。本版不新增此类普适验收声明。

## 本版未实现范围

- 投影能带、NCL/SOC、联图／多计算对比、结构对比与电荷可视化等进一步后处理。
- 形成能／吸附能计算、催化台阶图、磁矩自动生成；后处理扩展批次 PP-M 后置，不随本版交付。
- VASPKIT 后处理／Skill、反折叠、表面／吸附、振动／声子及完整自动连续／并行执行。
- 双端项目根目录初始化、超算选择器新建目录与完整新手流程指引，仍需使用已有工作区。
- 不分发真实赝势，继续禁止通过 VASPKIT 生成、拼接或覆盖 POTCAR；现有本地赝势组装使用用户有权使用的库。
