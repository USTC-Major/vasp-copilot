# VASP-Copilot v0.5.0：结果后处理与桌面体验更新

v0.5.0 将已有计算结果接入绘图流程，同时简化 Windows 桌面启动与设置。可以从本地文件开始，也可以预览并确认取回已提交任务的结果；缓存后继续分析，无需保持超算连接。

## 本次更新

- **结果直接变成图形：** 支持总 DOS、XML 原子／轨道投影 DOS 与常规路径能带。能量窗、参考与投影选择自动保存，已有分析可以重新打开。
- **任务结果接入：** 选择具体任务与执行尝试，先核对文件和大小，再确认取回为独立本地副本。需要更新时建立新快照，保留原分析。
- **绘图与导出更方便：** 导出白底 PNG、CSV 和 JSON，调整图片尺寸、比例与配色，保存默认配色；数据导出保留来源与文件指纹。
- **桌面一个入口：** 完整解压后双击根目录 `VASP-Copilot.exe`，统一“设置”集中管理启动、模型、材料服务、超算与绘图偏好。
- **升级保留已有环境：** 兼容已知旧启动设置与可确认的数据根；旧来源冲突时明确选择，路径无法确认时给出处理提示，保留旧配置和数据。

AI 是可选功能。工作流、确定性诊断、基础任务与后处理均可在未配置模型时使用。

## 下载与升级

- [Windows 完整桌面包](https://github.com/USTC-Major/vasp-copilot/releases/download/v0.5.0/vasp-copilot-0.5.0-windows-x64.zip)
- [源码包](https://github.com/USTC-Major/vasp-copilot/releases/download/v0.5.0/vasp-copilot-0.5.0-source.zip)
- [快速开始与升级说明](https://github.com/USTC-Major/vasp-copilot/releases/download/v0.5.0/QUICKSTART.md)

退出旧桌面，将新包完整解压到新目录，双击包根目录 `VASP-Copilot.exe`。核对当前包目录，Python 可留空自动检测；遇到旧设置来源选择或数据路径提示时按说明处理。不要只复制 EXE、覆盖运行中的包或删除旧数据。

需要已有 Windows x64、标准 CPython 3.11–3.14 x64、.NET Framework 4.8 和 WebView2 Runtime。桌面包无需 Node/npm；首次依赖准备需直连官方 PyPI，后续核验复用。

## 使用范围

后处理支持未压缩的非自旋／普通共线结果。DOSCAR 当前提供总 DOS，PDOS 需含投影数据的 `vasprun.xml`；常规能带需同次计算的倒空间 line-mode `KPOINTS`。

投影能带、NCL/SOC、形成能／吸附能、催化台阶图、磁矩自动生成等仍待后续。Python 3.15 暂不支持完整应用；本项目不提供真实赝势。取回成功、解析成功或曲线生成均不能代替科学收敛判断。
