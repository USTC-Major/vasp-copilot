发布版本：v0.4.0，日期：2026-10-09。负责人在全量差距核查后批准发布现有能力，未授权本轮新增功能。此前rc.1及多项专项人工验收通过，rc.3-fix2完整人工复测未单独收口，不因发布而改记为通过。正式包来源、准确提交CI和哈希见发布附件 release-provenance.json。发布前基线为PR49合并main `7df61f22c79f359e9af74af9e213a764a59cda9f`。

## 范围

包含基线已合入的科研工具界面、桌面服务管理、工作流/诊断/AI链路改进、本地PAW-PBE库管理、有限推荐、确认POTCAR拼接和工作流接入。通过本版的“启动完整功能.cmd”默认开放已实现的真实功能入口，AI服务默认启动；配置、材料条件及操作确认仍需满足。普通入口与隔离入口维持原行为。

原开发目录的非共线/SOC MAGMOM分量检查、OUTCAR完整性与数值错误分离、IssueCard缺tags容错及回归测试已经由 `f6ccc92` 进入main；本轮不复制或重复合入，原文件保留。

VASPKIT后处理/Skill、反折叠、表面/吸附、振动与声子、更多赝势家族及完整自动连续执行均不纳入本版。A-4完整页面指引独立接续，本包提供必要使用说明。

## 工作流复测修订（2026-10-09）

本轮修订针对默认精度、重复提示与切换页面丢失草稿。具体软件验证与候选包状态以交付回执为准，不沿用旧候选的通过结果。

- standard 档按任务提供起点：relax 保留 EDIFF=1e-5、KPPA=1000；static 使用 EDIFF=1e-6、KPPA=1500；DOS 使用 EDIFF=1e-6、KPPA=2000。NELM 保持 100，同档 ENCUT 保持一致，不因切换步骤默认增加 ADDGRID。quick/high 与用户显式补丁仍按所选配置处理。
- KPPA 是项目采样预设，整数化后的实际网格可能相同，不能代替体系的收敛测试。DOS 仍依赖前序自洽 CHGCAR；DFT+U 等既有确认和继承要求不变。
- 通用“初始推荐”说明在配方顶部展示一次，步骤中的具体警告、冲突和补丁提示继续显示；原始配方数据保留。
- 同一应用会话内跳转至赝势设置再返回时恢复工作流草稿。刷新、关闭或重启后的恢复不在此范围；未完成操作不自动重试，最终确认不会自动执行。新建工作流清空草稿。

参数依据：[VASP EDIFF](https://vasp.at/wiki/EDIFF)、[ICHARG](https://vasp.at/wiki/ICHARG)、[ADDGRID](https://vasp.at/wiki/ADDGRID)。1e-6 有官方建议依据；上述具体 KPPA 数字是本项目初始选择。

复测应覆盖：默认 INCAR/KPOINTS 与计划一致；手工覆盖仍生效；具体警告不被隐藏；未提交表单和已生成计划分别跨页面恢复；赝势确认失效后需重新核对；新建后旧请求不能污染新草稿。
