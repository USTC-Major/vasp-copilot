## 工作流复测修订（2026-10-09）

本轮修订针对默认精度、重复提示与切换页面丢失草稿。具体软件验证与候选包状态以交付回执为准，不沿用旧候选的通过结果。

- standard 档按任务提供起点：relax 保留 EDIFF=1e-5、KPPA=1000；static 使用 EDIFF=1e-6、KPPA=1500；DOS 使用 EDIFF=1e-6、KPPA=2000。NELM 保持 100，同档 ENCUT 保持一致，不因切换步骤默认增加 ADDGRID。quick/high 与用户显式补丁仍按所选配置处理。
- KPPA 是项目采样预设，整数化后的实际网格可能相同，不能代替体系的收敛测试。DOS 仍依赖前序自洽 CHGCAR；DFT+U 等既有确认和继承要求不变。
- 通用“初始推荐”说明在配方顶部展示一次，步骤中的具体警告、冲突和补丁提示继续显示；原始配方数据保留。
- 同一应用会话内跳转至赝势设置再返回时恢复工作流草稿。刷新、关闭或重启后的恢复不在此范围；未完成操作不自动重试，最终确认不会自动执行。新建工作流清空草稿。

参数依据：[VASP EDIFF](https://vasp.at/wiki/EDIFF)、[ICHARG](https://vasp.at/wiki/ICHARG)、[ADDGRID](https://vasp.at/wiki/ADDGRID)。1e-6 有官方建议依据；上述具体 KPPA 数字是本项目初始选择。
