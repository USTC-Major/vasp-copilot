# VASP-Copilot v0.4.0

发布日期：2026-10-09。

本版带来统一的科研工具界面、Windows桌面服务管理与自动依赖准备，以及本地授权赝势库到工作流POTCAR交付的完整首期流程，同时改进工作流、诊断和智能模式的日常使用体验。

## 下载与启动

- **Windows用户：** 下载 `vasp-copilot-0.4.0-windows-x64.zip`，完整解压，双击根目录 `启动完整功能.cmd`。包含生产前端与桌面程序，运行无需Node/npm。
- **源码用户：** 下载 `vasp-copilot-0.4.0-source.zip`，按包内源码安装指南构建运行。
- 电脑需已有CPython 3.11/3.12 x64、.NET Framework 4.8及WebView2 Runtime。完整功能入口首次联网自动创建专用环境并安装锁定依赖，之后复用；不捆绑或自动安装Python。
- 升级请先退出旧桌面，并在启动设置将安装目录改为**本次解压根目录**。新EXE可能仍读取旧路径；不要覆盖运行中的旧目录。
- 包内 `0.4.0快速开始.md` 提供使用和升级步骤。附件SHA256清单和发布来源JSON可用于核对下载及代码来源。

## 主要更新

1. **科研工具界面与桌面体验：** Graphite/冷蓝深浅主题、全模块布局、可交互工作流步骤图和带晶轴的结构预览；桌面自动管理端口与服务状态，支持依赖准备进度、取消和重试。
2. **本地POTCAR工作流：** 授权PAW-PBE库登记、中文/空格路径、手动刷新、有限有来源推荐，按物种顺序人工确认变体后独立拼接或加入工作流ZIP。不会内置、下载或公开分发赝势。
3. **工作流：** PBE/PBE+U常规能带与高对称路径、Dudarev/Liechtenstein参数选择、Recipe分类和来源详情；standard的static/DOS使用EDIFF=1e-6、KPPA=1500/2000，保留手动覆盖。
4. **诊断：** 总能量与电子步能量变化双视图、MAGMOM参考排列对比、清晰的修复状态/差异和候选文件下载；模型解释复用智能模式配置。
5. **MP与使用体验：** 有可信映射时显示数字编号并保留API导入身份；修复MP请求阻塞健康响应、通用推荐重复和切页丢失工作流草稿，服务临时恢复后保留页面。

## 已知限制

- 工作流草稿仅在当前应用会话内支持离开页面再返回；刷新、关闭或重启不持久恢复。
- 安装目录沿用旧偏好，需要手动检查；首次依赖下载需直连官方PyPI，暂不继承代理设置。
- 项目双端根目录/独立任务目录初始化、超算目录选择器新建、完整A-4新手指引仍待后续。
- 正式VASPKIT后处理/AI Skill、反折叠、表面/吸附、振动/声子、更多赝势家族及一次授权的连续执行/并行/自动纠错不包含在本版。
- 科学输入和赝势推荐是起点，不能替代收敛测试；MAGMOM对比不能证明磁性基态。禁止通过VASPKIT生成或拼接POTCAR。
- 软件CI、受控桌面/Docker检查和历史真实样例分别成立，不代表所有模型、MP/SSH/HPC环境或科学结果均已验收。最新工作流修订的完整人工复测未单独收口，发布不将其改记为已通过。
