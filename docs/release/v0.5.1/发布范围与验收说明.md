## 表面与吸附边界

- 晶面依据用户输入晶胞，不静默标准化。固定方向沿直接晶格基矢；切面或扩胞无法可靠保留混合方向约束时明确拒绝。
- 有序、有限、右手晶胞；体相最多 512 原子，单模型最多 2048 原子。hkl 分量为 -3 到 3 且不全为零，面内倍数 1 到 8；最多 16 终止面、合计 8192 原子，超限不截断。
- XYZ 限普通单帧、Å 坐标、128 原子／64 KiB。每个候选只放一个吸附物，最多 16 候选且合计不超过 8192 原子；多选生成多个模型，不是共吸附。
- 自动位点基于顶层和周期平面的几何网格，有顶层原子数与晶胞形状限制；不能完成自动枚举时可使用手动位置。它不提供稳定性排序、任意晶面的完整化学位点识别或自动 fcc／hcp 判定。
- 厚度和周期空隙是几何量，距离筛查不是普适成键判据。理想 Pt／CO 示例不能替代表面极性、磁性、结构优化或数值收敛验证。
- Workflow 保留已接入快照；后续 CAT 编辑不自动同步。一次只接入一个模型，不自动建立清洁表面、气相参考与全部候选的整套任务，不自动提交 VASP。
- 表面弛豫固定晶胞，采用 `ISIF=2`；倾斜 c 使用显式纯面内网格，不生成四面体连接表，相关 `ISMEAR=-4/-5/-14/-15` 组合明确拒绝。表面模型不使用体相高对称能带路径。

精确格式、存储上限与操作见[表面合同](../../development/cat-stage/README.md)、[吸附合同](../../development/cat-stage/ADSORPTION.md)和 [Workflow 合同](../../development/cat-stage/WORKFLOW.md)。

## 能量与结果来源边界

- 默认读取最后完整可归属的离子能量汇总块，分别保留 sigma→0、without entropy 和 TOTEN；每卡统一字段，缺值不隐式回退。尾部截断、多个运行段、非有限数值和缺元数据如实处理。
- 自动解析比较面向元数据充分的普通 PBE／PBE+U SCF 静态或弛豫。非 SCF、MD、响应／GW、NCL／SOC 等不能仅凭标量能量获得支持；人工来源保留方法与收敛未知标记。
- 吸附能需确认清洁表面、吸附物参考、参考单元数与目标数量，并校验完整组成。分子原子数不能代替分子个数；不同吸附数量不伪装为同条件位点排名。
- 材料形成能相对于用户指定元素参考，按参考胞原子数归一化，显示 eV/计算胞和 eV/atom。单元素组成不证明标准态或正确磁态，负能差不证明全局稳定性。
- 运行结束、电子收敛与离子收敛独立显示。未知或未完成来源可在明确接受风险后纳入，标记随结果保留；硬错误、缺必要能量／参考、组成和计量冲突不能绕过。
- 只导入未压缩 OUTCAR：单份最多 64 MiB，每能量任务最多 128 MiB／100 样本，能量缓存总额 1 GiB，CSV 最多 1 MiB。原值与人工修订分开；回导样本表是新的 CSV 自述来源，不继承 OUTCAR 验证或卡片确认。
- 能量作业来源绑定可信提交身份与当前 attempt，可预览确认后读取排队／运行中或终态的稳定完整 OUTCAR。传输中变化、身份变化或中断不发布完整缓存，不停止作业；已有完整缓存可离线复用。
- DOS／能带沿用 v0.5.0 的受限未压缩格式和普通共线支持；其新取回仍限于有提交记录的当前 `completed`、`failed` 或 `not_converged` 终态尝试。能量快照策略不扩大 DOS／能带入口范围。
- 删除能量任务只清理软件内该任务数据与对应浏览器草稿，保留原始 OUTCAR、用户文件及其他任务；删除卡保留任务样本。哈希与来源元数据证明可追溯和字节一致，不能证明科学适用性。

当前操作以[多计算卡使用说明](../../development/pp-stage/PP22-MC_使用与复测.md)为准；公式、CSV 与来源约定见[基础能量范围](../../development/pp-stage/PP-22A_范围与验收.md)。

## 桌面兼容与升级

- 沿用 Windows x64、标准 CPython 正式版 3.11／3.12／3.13／3.14、精确依赖与哈希锁，本版不升级依赖。
- 需已有 .NET Framework 4.8 和 WebView2 Runtime；不捆绑系统 Python 或安装器，运行桌面包无需 Node/npm。首次专用依赖准备直连官方 PyPI，不继承代理或用户 pip 源。
- Python 3.15 暂缺关键 Windows 二进制依赖；32 位、ARM64、自由线程、预发布及未知未来解释器未纳入支持。
- 先退出旧实例，完整解压新包，从根目录 `VASP-Copilot.exe` 启动。保存目录指向另一包时核对提示，避免前后端混用。
- 正式偏好位于 `%LOCALAPPDATA%/VASP-Copilot/desktop/preferences.json`，旧配置原件保留；来源冲突需选择，只延续可可靠确认的旧数据根。无法确认时停止并说明，不搬动数据库、凭据或科研文件。
- CAT 服务端草稿与能量成功保存的任务可重开；未应用输入、浏览器草稿与服务端保存分别处理。Workflow 草稿只在当前会话切页后恢复，重启或刷新前需保留必要内容。

升级步骤见[0.5.1 快速开始](../../../0.5.1快速开始.md)。旧版本发布文档与附件保持各自原有范围。
