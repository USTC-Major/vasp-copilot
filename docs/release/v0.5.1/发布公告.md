# VASP-Copilot v0.5.1：表面建模与基础能量分析

v0.5.1 增加表面与单吸附物建模，以及吸附能／材料形成能分析。可以从结构准备开始，也可以直接导入已有 OUTCAR；两条流程都无需配置 AI。

## 本次更新

- **表面与吸附模型：** 从体相切晶面或导入已有表面，保存草稿、选择终止面，设置固定层与逐原子约束；放置单原子或 XYZ 分子，生成几何位点与多个独立候选，预览并导出。
- **模型接入 Workflow：** 选一个清洁表面或有效吸附候选，保留原子映射、约束和来源。默认准备固定晶胞弛豫与静态计算，采用二维面内 k 点，重新核对计划与 POTCAR 选择后导出。
- **基础能量：** 批量读取 OUTCAR，或使用手填、CSV 和已有作业快照；核对参考、能量口径与计量后计算吸附能或相对于指定元素参考的材料形成能，导出可追溯的 CSV／JSON。
- **独立任务与多计算卡：** 每个能量任务管理自己的样本和结果，同一任务内多卡复用样本，各自确认、锁定和计算。共享样本修改显示影响范围；任务改名保留结果，删除保留原始文件与其他任务。
- **查看器改进：** 旋转保持缩放比例，支持滚轮缩放；三维吸附预览只显示已选位点。

原工作流、诊断、计算任务、本地授权赝势库及 DOS／能带绘图延续 v0.5.0。Windows 单入口、统一设置、CPython 3.11–3.14 x64 支持和锁定依赖保持不变。

## 使用边界

表面终止面与吸附位点是几何候选，每个吸附模型只放置一个吸附物；接入 Workflow 不自动建立整套作业或提交 VASP。表面参数、磁性、真空与 k 点仍需自行核对和收敛测试。

基础能量自动比较面向元数据充分的普通 PBE／PBE+U SCF 静态或弛豫。参考态、能量字段和分子／原子单元计量需明确确认；解析成功、接受未知状态或负能差不能证明科学收敛与全局稳定性。

自由能自动修正、缺陷形成能、相图、共吸附、催化台阶图、投影能带、NCL/SOC 和磁矩自动生成等仍待后续。本项目不提供真实赝势。
