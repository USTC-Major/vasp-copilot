新增任务列表读取失败说明与原查询的显式重试入口；项目或任务列表读取失败时，不以“没有项目／任务”冒充真实空态。没有修改 API、查询配置或重试策略。

测试使用既有 MSW、组件桩与合成响应，没有调用真实 MP、模型、SSH、HPC 或用户服务。没有为视觉验收在用户目录创建文件或提交计算。

## 独立复测方法与限制

先在 `frontend` 执行 `npm ci --offline --no-audit --no-fund`、`npm run build` 与 `npm run lint`。离线浏览器复测由独立本地静态服务加载 `dist`，按现有接口形状提供合成项目／任务数据；未知 `/api` 与 `/ai` 请求明确返回不可用，不代理实际用户服务。合成服务器和验收数据不混入生产构建，本回执不表示任何试用服务仍在运行。

1. 在宽屏及 375px、深浅主题下查看长项目名、任务标题、目标和目录；用键盘切换项目，打开创建与目录弹窗，核对输入、按钮、焦点和选择状态。
2. 合成任务并列设置 monitoring、failed、unknown 作业及各自 `attempt_id`，加入 pending 人工确认卡与绑定身份；检查真实字段和禁用门槛，没有选择当前计算时不能发送准备／提交请求。
3. 使用 recovering、stopped、过期 `last_success_at` 和 `last_error` 检查采集说明；保留最后已知状态，不据连接问题判断计算失败。用 404 与 503 分别检查任务缺失和读取失败恢复。
4. 查看输入、长路径、文件范围、完整确认卡及逐项回执；主题切换不能减少完整文本、身份、到期与软链接风险证据。检查结果取回门槛及任务／尝试切换后的旧选择失效。
5. 创建／删除确认只在合成数据或隔离验收目录进行。删除说明必须保留；如验证文件下载，应另行取得落盘文件及内容证据。

本批是前端视觉与原操作边界回归，不证明真实集群调度、材料数据质量、科学收敛、模型效果或原生桌面下载。生产构建仍有既有大资源块提示；没有为本批引入依赖或拆分科学实现。
